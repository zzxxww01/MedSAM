研究背景与意义

医学图像分割的重要性

  • 计算机辅助诊断、术前规划和放疗勾画的关键基础能力
  • 直接影响器官体积估计、病灶边界判读及治疗决策

医学图像分割的长期痛点

类别不平衡
前景像素占比低，训练易被背景主导
边界模糊
困难像素对临床可用性影响大，但常被简单样本淹没

国内外研究现状

医学图像分割模型演进

  • 传统方法：阈值、区域生长、活动轮廓 → 依赖手工特征
  • 深度学习时代：FCN → U-Net → nnU-Net → TransUNet
  • 视觉基础模型：SAM → MedSAM → 提示式分割新范式

MedSAM的优势与局限

✓ 优势
• 150万+医学图像训练
• 10种成像模态覆盖
• 提示式交互灵活
✗ 局限
• 类别不平衡建模不足
• 高频边缘特征欠缺
• 小器官分割受限

研究问题与核心挑战

挑战1：双重类别不平衡

  • 类间不平衡：前景vs背景像素比例悬殊（<1% vs >90%）
  • 类内不平衡：易样本vs难样本（边界区域）分布不均
  • 现有损失函数（Dice+CE）未显式建模

挑战2：ViT局部特征缺陷

  • 全局自注意力机制缺乏局部高频特征捕获能力
  • 导致器官边界过度平滑
  • LoRA等参数高效微调在复杂任务中存在局限

Balance Loss：联合平衡损失框架

设计思路

Inter-CBL
类别间平衡

• 困难背景样本挖掘
• 前景/背景数量对齐
• 避免背景梯度主导
Intra-CBL
类别内难度加权

• 阈值划分易/难样本
• 难样本权重提升
• 强化边界学习
L = λdice · Ldice + λinter · Linter + λintra · Lintra

LG-Adapter：多尺度局部特征增强

核心创新

  • 双路径设计：深度可分离卷积 + 膨胀卷积
  • 多尺度融合：捕获不同感受野的局部特征
  • 参数高效：仅增加0.15%参数量
与LoRA的对比
• LoRA (r=4)：冻结主干微调，性能提升有限
• LG-Adapter：显式注入局部归纳偏置，弥补ViT高频缺陷

实验设计

数据集与评估指标

FLARE22数据集
• 13类腹部器官
• CT影像
• GT box prompt
评估指标
• DSC (Dice系数)
• HD95 (豪斯多夫距离)
• ASD (平均表面距离)

消融路径

A0 (基线) → A3R3 (+Balance Loss) → C2 (+LG-Adapter) → C3 (完整方案)

实验结果

整体性能提升

DSC: 0.9620 | HD95 ↓56.9% | ASD ↓57.8%

关键发现

  • Balance Loss显著提升小器官召回率（肾上腺、十二指肠）
  • LG-Adapter有效改善边界质量，HD95大幅下降
  • 两阶段训练策略缓解冷启动噪声
  • LoRA (r=4)在复杂多器官任务中性能受限

消融实验分析

Balance Loss消融

• Inter-CBL单独：DSC +2.3%
• Intra-CBL单独：DSC +1.8%
• 联合使用：DSC +3.5%
→ 协同增效验证

LG-Adapter消融

• 单路径：HD95 -28%
• 双路径：HD95 -56.9%
• vs LoRA: DSC +4.2%
→ 多尺度必要性
LoRA秩消融：r=4最优，r↑性能未提升 → 低秩假设在密集预测任务中局限性

研究总结

主要贡献

  • Balance Loss：联合建模类间/类内不平衡，分段权重+两阶段训练
  • LG-Adapter：双路径多尺度局部特征增强，0.15%参数开销
  • LoRA消融：揭示低秩微调在复杂分割任务中的局限性
  • 系统评估：完整消融路径，同口径对比，FLARE22基准验证
核心价值：为大模型在医学领域的精细化应用提供可行优化路径

未来工作展望

  • 三维扩展：将Balance Loss与LG-Adapter扩展到3D体积分割
  • 多模态融合：探索CT+MRI联合分割
  • 弱监督学习：降低对精细标注的依赖
  • 实时推理：模型压缩与加速，面向临床部署
  • SAM 2适配：探索视频医学图像的时序一致性分割
