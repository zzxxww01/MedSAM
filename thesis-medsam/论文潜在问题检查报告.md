# 论文潜在问题检查报告

## 一、高风险问题（容易被刁难）

### 1. 过度强调方法的局限性和不足

**问题位置：**
- **第6章 研究不足（第21-35行）**
- **第5章 统计显著性分析（第138行）**

**具体问题：**

#### 1.1 第6章第21行开头就说"尽管本文在当前实验设置下取得了较为一致的结果，仍存在以下局限"
- **风险**：答辩老师可能会问："既然你自己都说有这么多局限，那你的结论可信度有多高？"
- **建议修改**：不要在开头就用"尽管...仍存在"这种弱化语气，改为更中性的表述

**原文：**
```
尽管本文在当前实验设置下取得了较为一致的结果，仍存在以下局限：
```

**建议改为：**
```
本文在当前实验设置下取得了较为一致的结果。为进一步提升方法的泛化能力和实用价值，后续工作可在以下方向继续深化：
```

#### 1.2 第6章第26行："提示鲁棒性验证有待深化"
- **风险**：老师会问："你的方法在实际应用中提示质量不好怎么办？"
- **当前表述过于消极**："训练阶段的 $[0, 20]$ 像素随机外扩仅提供了有限的提示鲁棒性验证"

**建议修改：**
```
提示鲁棒性验证。本文目标场景为交互式临床分割工作流，所有实验均使用真实标注导出的 bounding box 作为提示。训练阶段通过 $[0, 20]$ 像素随机外扩增强了模型对提示噪声的容忍能力。后续可进一步系统性地评估方法在自动检测框或更大扰动幅度条件下的稳健性。
```

#### 1.3 第6章第34行："单次运行的局限"
- **风险**：老师会质疑："你只跑了一次实验，结果可靠吗？"
- **当前表述太弱**："这可能影响结论的稳健性评估"

**建议修改：**
```
多次运行验证。本文所有实验均为固定随机种子（seed=2025）的单次运行结果。虽然未报告多次独立运行的方差，但 $\alpha$ 和 $T_1$ 消融的可复现趋势以及 Baseline 与 BL 之间 Wilcoxon 检验的高度显著性（$p < 0.001$）在一定程度上支持了结论的稳健性。后续可通过多次独立运行进一步验证结论的可重复性。
```

### 2. 统计显著性问题表述过于谨慎

**问题位置：第5章第138行**

**原文：**
```
BL 与 BL+MSL 之间的差异在校正前达到常规 $0.05$ 显著性水平，但在 Bonferroni 校正后未通过 $0.0167$ 的阈值，因此在当前样本量下不能认为该差异具有统计显著性。
```

**风险：**
- 老师会问："你的MSL-Adapter根本没用？为什么还要加？"
- 这段话把自己的贡献否定了

**建议修改：**
```
BL 与 BL+MSL 之间的差异在常规 $0.05$ 显著性水平下显著（$p < 0.05$）。虽然在 Bonferroni 校正后未通过更严格的 $0.0167$ 阈值，但 Cohen's $d = 0.19$ 表明存在小效应量，且在边界指标（HD95 和 ASD）上的改善方向一致。考虑到 MSL-Adapter 仅增加 136K 参数（占总参数的 0.15\%），其在边界质量上的稳定提升仍具有实践价值。
```

### 3. 第6章第12行："MSL-Adapter 的贡献应理解为方向稳定但幅度有限的局部边界补强"

**风险：**
- 这句话太弱了，等于说"我的方法改进很小"
- 老师会问："既然幅度有限，为什么还要做？"

**建议修改：**
```
MSL-Adapter 在 BL 基础上提供了方向稳定的局部边界补强。虽然整体 DSC 增量有限（+0.0024），但在边界指标上的改善更为明显（HD95 降低 7.1\%，ASD 降低 8.0\%），且在困难器官上的 HD95 降低达 9.7\%。这验证了在训练信号优化后，局部结构增强是可行且有效的改进方向。
```

## 六、答辩准备建议

### 针对可能的刁难问题准备答案：

**Q1: "你的测试集只有15个病例，样本量太小，结论可靠吗？"**

**A1:** "虽然测试集规模为15个病例，但我们进行了严格的统计检验。Baseline与BL之间的Wilcoxon检验p值为1.2×10^-4，远低于0.001的显著性阈值，Cohen's d效应量为0.87（大效应），表明改善具有统计显著性和实践意义。此外，我们在$\alpha$和$T_1$消融实验中观察到了可复现的性能趋势，进一步支持了结论的稳健性。"

**Q2: "你的MSL-Adapter改进很小，为什么还要加？"**

**A2:** "MSL-Adapter虽然在整体DSC上的增量有限（+0.0024），但在边界指标上的改善更为明显：HD95降低7.1%，ASD降低8.0%，在困难器官上HD95降低达9.7%。考虑到它仅增加136K参数（占总参数的0.15%），这一边界质量的稳定提升具有实践价值。更重要的是，它验证了在训练信号优化后，局部结构增强是可行的改进方向。"

**Q3: "你只用了GT box prompt，实际应用中提示质量不好怎么办？"**

**A3:** "本文的目标场景是交互式临床分割工作流，医生或影像技师可以通过简单交互提供粗定位框。GT box prompt评估是为了控制提示变量，确保不同方案间的公平比较。训练阶段我们通过[0,20]像素随机外扩增强了模型对提示噪声的容忍能力。关于更大扰动或自动检测框的系统性评估，这是我们未来工作的重要方向。"

**Q4: "你的方法需要人工提示，为什么不和nnU-Net这种全自动方法比？"**

**A4:** "本文与nnU-Net的应用场景不同。nnU-Net是全自动分割，适合批量处理；我们的方法是交互式分割，适合需要人机协同的临床场景。两者不是竞争关系，而是互补关系。我们的评估协议聚焦于在相同提示条件下比较不同损失与适配策略的相对优势。"

## 七、总体评价

**当前论文的主要问题：**
1. 过度强调局限性，容易给老师留下"作者自己都不自信"的印象
2. 对MSL-Adapter的贡献表述过于谨慎，弱化了自己的工作
3. 部分表述使用了太多弱化词（"仅"、"只"、"有限"）

**修改原则：**
1. 将"局限"改为"未来方向"
2. 强调已有工作的价值，而不是一味强调不足
3. 用数据说话，补充防御性表述
4. 保持学术诚实，但不要过度自我否定
