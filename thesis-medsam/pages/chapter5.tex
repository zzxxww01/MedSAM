\chapter{综合实验与结果分析}

前述第3章和第4章分别从损失函数层面和架构层面提出了改进方案。本章在统一的实验框架下，对全部方案进行系统性的同口径评估。通过完整的消融路径（A0$\rightarrow$A3R3$\rightarrow$C2$\rightarrow$C3），本章将依次呈现实验设置、完整消融结果、核心方案对比、定性可视化分析以及对关键现象的深入讨论。

\section{实验与评估设置}

\subsection{数据集与预处理}

本文所有实验的评估统一在 FLARE22 腹部多器官 CT 数据集上进行\cite{ma2022flare}。FLARE22（Fast and Low-GPU-memory Abdomen Segmentation Challenge）是面向腹部器官分割的国际标准评测，提供了涵盖 13 类腹部解剖结构的标注数据，具体类别包括：肝脏（Liver）、右肾（Right Kidney）、脾脏（Spleen）、胰腺（Pancreas）、主动脉（Aorta）、下腔静脉（Inferior Vena Cava）、右肾上腺（Right Adrenal Gland）、左肾上腺（Left Adrenal Gland）、胆囊（Gallbladder）、食管（Esophagus）、胃（Stomach）、十二指肠（Duodenum）和左肾（Left Kidney）。

训练阶段联合使用了 FLARE22\cite{ma2022flare}与 AMOS22\cite{ji2022amos}两个公开数据集的 CT 子集。FLARE22 公开标注数据中划分出 40 例病例用于训练，AMOS22 提供了额外的大规模腹部 CT 标注数据。由于 MedSAM 采用 bounding box 提示驱动的二值分割范式，每个训练样本仅需对框内目标进行前景/背景分割，无需跨数据集的标签 ID 对齐，因此可直接聚合两个数据集以增大训练样本量。

数据预处理阶段对两个数据集执行了统一的操作：
\begin{enumerate}
  \item 将原始 CT 切片统一裁剪并调整至 $1024 \times 1024$ 像素分辨率，以匹配 MedSAM 的 ViT-Base 输入规格\cite{ma2024medsam}；
  \item 应用软组织窗（window level = 40, width = 400）进行强度归一化，增强腹部器官的对比度；
  \item 将处理后的数据存储为 NPY 格式，便于高效批量加载。
\end{enumerate}

测试阶段严格划分出 FLARE22 中 \textbf{10 例}未参与训练的独立病例进行同口径联合评估，确保所有实验方案在完全相同的数据分布上进行公平对比。

需要说明的是，本文所有实验的推理阶段均使用真实标注导出的 bounding box 作为提示（ground-truth box prompt），这与 FLARE22 挑战赛中的全自动分割方法不同。Box prompt 为模型提供了器官级别的空间先验信息，因此本文报告的性能指标不宜与 FLARE22 排行榜上的全自动方法进行直接对比。此外，本文的 10 例测试集系从 FLARE22 公开训练集中自行划分，而非挑战赛的官方封闭测试集。上述设定旨在保证内部消融实验的公平可比性，而非追求与外部基准的横向对比。

\subsection{评价指标}

本文选取三种医学分割领域广泛采用的客观评价指标\cite{taha2015metrics}：

\begin{enumerate}
  \item \textbf{Dice Similarity Coefficient (DSC)}：衡量预测掩码与真实标注的宏观区域重叠度，定义为 $\text{DSC} = 2|Y \cap \hat{Y}| / (|Y| + |\hat{Y}|)$，取值范围 $[0, 1]$，越高越好。DSC 是医学分割最核心的全局一致性指标\cite{milletari2016vnet}。
  \item \textbf{95\% Hausdorff Distance (HD95)}：衡量预测边界与真实边界之间的最大偏差（取第 95 百分位以剔除极端 outlier），单位为像素，越低越好。HD95 直接反映分割结果在边界区域的最坏情况表现。
  \item \textbf{Average Surface Distance (ASD)}：衡量预测表面与真实表面之间的平均距离，单位为像素，越低越好。ASD 综合反映整体表面吻合质量。
\end{enumerate}

三种指标从"全局重叠→边界极端偏差→平均表面质量"三个维度构成完整的评估体系，能够全面刻画分割方法的临床适用性。

\subsection{训练超参数与硬件环境}

所有实验均采用统一的训练配置，确保消融结论的可比性：

\begin{itemize}
  \item \textbf{训练集规模}：联合使用 FLARE22 训练子集（40 例 CT 病例）与 AMOS22\cite{ji2022amos} CT 子集，合计数千张含前景标注的 2D CT 切片
  \item \textbf{优化器}：AdamW\cite{loshchilov2019adamw}，学习率 $\text{lr} = 1 \times 10^{-4}$，权重衰减 $\text{weight\_decay} = 0.01$
  \item \textbf{学习率调度}：余弦退火（Cosine Annealing），从初始学习率衰减至 $1 \times 10^{-6}$
  \item \textbf{批量大小}：$\text{batch\_size} = 8$
  \item \textbf{训练轮次}：$\text{epochs} = 200$
  \item \textbf{数据增强}：训练阶段采用随机水平翻转和随机垂直翻转；未使用弹性变形或颜色抖动
  \item \textbf{随机种子}：全部实验固定随机种子（seed=2024）以确保可复现性；表中数值为单次运行结果
  \item \textbf{模型选择}：本文统一使用最后一个 epoch（第 200 轮）的模型权重进行测试集评估，未设置独立验证集进行 early stopping 或最优模型选择。该策略虽简化了实验流程，但可能导致个别方案存在轻微过拟合，这一局限性将在第6章进一步讨论
  \item \textbf{Balance Loss 参数}（A3R3 及后续方案）：$\alpha = 0.5$，$\beta = 1.0$，$\gamma = 1.0$，$\text{stage1\_epochs} = 50$，$\text{intra\_threshold} = 0.9$，$\text{hard\_weight} = 2.0$，$\text{neg\_ratio} = 3.0$
  \item \textbf{硬件环境}：4$\times$ NVIDIA V100 GPU（32GB 显存），单次完整训练（200 epochs）耗时约 52 小时
  \item \textbf{Prompt Encoder}：全程冻结，不参与梯度更新
  \item \textbf{推理提示}：使用真实标注导出的 bounding box 作为提示（GT box prompt）
\end{itemize}

\subsection{Balance Loss 组件消融分析}

Balance Loss 各组件的详细消融分析已在第3章给出，此处仅从全局视角归纳关键结论。

\textbf{（1）单组件效果。} A1（单独 Inter-CBL）与 A0 持平（DSC 差异 $<$0.01\%），说明单纯的类别间重平衡收益有限。A2（单独 Intra-CBL）则带来显著提升（DSC +1.2\%，HD95 $-30.3\%$），证明类内困难样本加权是性能提升的主要驱动力。A0-focal（Dice+Focal Loss，$\alpha_{focal}=0.25$，$\gamma=2.0$）的 DSC 为 0.9391，未超越 Dice+CE 基线，而 A2 在相同调参成本下显著优于 A0-focal（DSC $+1.4\%$），表明离散分段加权策略具有更好的开箱即用性能。

\textbf{（2）组合退化与根因定位。} A3（$\alpha=1.0$）联合使用两组件后出现严重退化（DSC $-5.1\%$）。本文通过控制变量实验提出两个竞争假设（H1：$\alpha$ 过大；H2：$T_1$ 过早），并通过单变量剥离实验验证：A3R2（仅延长 $T_1$ 至 100，保持 $\alpha=1.0$）几乎未恢复（DSC=0.9044），而 A3R3（仅降低 $\alpha=0.5$，保持 $T_1=50$）实现全面最优（DSC=0.9596），确认 $\alpha$ 过大为退化首要因素。A3R1（$\alpha=0.5$，$T_1=70$，DSC=0.9541）介于两者之间，表明切换时机为次要因素。详细的逐步推导过程参见第3章第5节。

\subsection{架构消融分析}

在锁定 A3R3 为损失主干后，本文进一步进行了架构层面的消融：

\textbf{（1）Cross-Attention 融合（C1）。} 在 A3R3 基础上引入基于 PANet\cite{wang2019panet}思想的跨病例 Cross-Attention 特征融合，DSC 从 0.9596 降至 0.9427（$-1.8\%$），HD95 升至 3.1582，ASD 升至 0.3816，出现显著退化。这表明直接的特征空间加和会破坏 MedSAM 基座已建立的语义表征结构，Cross-Attention 融合路线不可行。

\textbf{（2）LoRA 冻结主干（C2）。} 在 A3R3 基础上冻结 Image Encoder 并插入 LoRA 低秩旁路（$r=4$），DSC 暴跌至 0.8796（$-8.3\%$），证明在当前配置下（低秩、仅 Q 投影层注入、无额外空间适配器），冻结主干的代价是巨大的（详见第4章分析）。

\textbf{（3）LG-Adapter 全参微调（C3）。} 在 A3R3 基础上保持全参微调并插入 LG-Adapter，DSC 达到 \textbf{0.9620}，HD95 降至 \textbf{2.0834}，ASD 降至 \textbf{0.2271}，三指标均为本文全部实验中的最优值。相比 A3R3，C3 在 DSC 上提升 0.25\%，HD95 进一步降低 7.4\%，ASD 进一步降低 7.8\%，表明在全参微调基础上引入卷积归纳偏置可有效提升全局重叠度的同时进一步优化边界质量。

\section{核心方案对比}

\subsection{总体性能评估}

    \hline

    C2 (LoRA PEFT) & 0.8796 & 7.7548 & 0.9965 \\

从表中可以归纳出以下核心发现：

\begin{enumerate}
  \item \textbf{A3R3 vs A0}：Balance Loss 将 DSC 提升 2.0\%（0.9407→0.9596），HD95 降低 53.4\%（4.83→2.25），ASD 降低 54.2\%（0.54→0.25），全面验证了第3章提出的损失重构策略的有效性。
  \item \textbf{C2 vs A3R3}：LoRA 冻结主干导致 DSC 下降 8.3\%、HD95 劣化 244.6\%、ASD 劣化 304.5\%，表明在低秩（$r=4$）且无额外空间适配器的条件下，冻结主干策略不适用于复杂多器官腹部分割任务（详见第4章）。
  \item \textbf{C3 vs A3R3}：LG-Adapter 在 A3R3 基础上将 DSC 提升至 0.9620（+0.25\%），HD95 从 2.25 降至 2.08（$-7.4\%$），ASD 从 0.25 降至 0.23（$-7.8\%$），三指标全面改善。这表明卷积归纳偏置对 ViT 高频特征盲区具有有效的互补增强效果，能够在损失优化之外进一步提升边界分割精度。
  \item \textbf{C3 vs A0}：从基线到最终方案，DSC 绝对提升 2.1 个百分点（0.9407→0.9620），HD95 降低 56.9\%（4.83→2.08），ASD 降低 57.8\%（0.54→0.23），在全部关键指标上实现了系统性进步。
\end{enumerate}

\end{enumerate}

\section{深入讨论}

\subsection{LG-Adapter 的多指标协同增效分析}

C3 方案在 DSC（0.9620）、HD95（2.0834）、ASD（0.2271）三指标上均取得了全面最优，相比损失优化方案 A3R3 实现了进一步的增量改善。本文从以下角度分析 LG-Adapter 的增效机制：

\begin{enumerate}
  \item \textbf{DSC 提升机制}：LG-Adapter 通过双路径深度可分离卷积注入局部空间先验，使得 ViT 编码器在全局语义建模之外获得了互补性的局部纹理特征。这种全局-局部特征的融合使模型能够更准确地捕获小器官（如肾上腺、十二指肠）的精细轮廓，从而提升整体重叠度。
  \item \textbf{边界指标改善}：HD95 从 2.25 降至 2.08（$-7.4\%$），ASD 从 0.25 降至 0.23（$-7.8\%$），表明卷积归纳偏置提供的高频边缘响应能够有效减少预测边界的极端偏差与平均表面误差。膨胀卷积路径（$d=2$）扩展的 $5 \times 5$ 感受野恰好覆盖了器官边缘的中等尺度纹理范围，对边界区域的精细化学习起到了关键作用。
  \item \textbf{增量收益的边际递减}：值得注意的是，C3 相比 A3R3 的提升幅度（DSC +0.25\%，HD95 $-7.4\%$）显著小于 A3R3 相比 A0 的提升幅度（DSC +2.0\%，HD95 $-53.4\%$），呈现出典型的边际递减效应。这表明在 DSC 超过 0.96 的高性能区间，进一步的架构微调所带来的增益趋于饱和，更大幅度的性能突破可能需要引入三维体积信息或跨模态数据等更根本性的改变。
\end{enumerate}

\subsection{测试集规模的局限性}

本文的全部实验基于 10 例测试集进行评估。该样本量较小，从统计学角度而言存在以下局限：

\begin{enumerate}
  \item 10 例样本的方差较大，个别 outlier 对均值指标（特别是 HD95）的影响显著，可能导致方案间的细微差异（如 C3 vs A3R3 的 HD95 差距）缺乏统计显著性。本文当前版本已给出逐病例 Wilcoxon 符号秩检验的占位结果（表~\ref{tab:wilcoxon_placeholder}），正式定稿时将由服务器端统计脚本回填真实 $p$ 值及置信区间，以量化指标差异的可靠性。
  \item 测试集来自单一中心、单一扫描协议，无法充分验证方法在跨中心、跨设备场景下的泛化能力。
  \item 未进行 k-fold 交叉验证，使得指标的不确定性难以充分量化。
\end{enumerate}

这些局限性将在第6章作为未来改进方向进一步讨论。

\subsection{负向实验的方法论价值}

本文的实验体系中包含了多个负向结果（A3 原始退化、C1 Attention 组合退化、C2 LoRA 退化），这些实验虽未产生正向性能提升，但在方法论层面具有不可替代的价值：

\begin{enumerate}
  \item \textbf{A3 退化}引出了系统性的变量剥离实验（R1/R2/R3），最终定位了 Inter-CBL 权重强度为退化根因，并导出了 A3R3 最优配置。如果没有 A3 的"失败"，A3R3 的"成功"就缺乏充分的因果解释。
  \item \textbf{C2 退化}为"低秩 LoRA 单独使用时在复杂医学域的不足"提供了实证支撑。在 LoRA 广泛应用的当下，该负向结果对医学影像社区在选择参数高效微调策略时具有参考价值，同时也提示更丰富的适配策略（如 LoRA 与空间适配器联合使用）可能是更可行的方向。
  \item \textbf{C1 退化}促使本文放弃了 Cross-Attention 融合路线，转向更有效的 LG-Adapter 设计，体现了"由实验驱动的方法演化"的研究过程。
\end{enumerate}

\section{本章小结}

本章在相同的 10 例腹部 CT 测试集上\cite{ma2022flare}，对本文提出的全部方案进行了系统性的同口径评估。通过完整的消融路径（A0→A1→A2→A3→A3R1/R2/R3→C1→C2→C3），本文验证了 Balance Loss 各组件的独立贡献与交互效应，通过控制变量实验定位了 A3 退化的根因，并最终展示了 C3 方案（Balance Loss + LG-Adapter，全参微调）在 DSC（0.9620）、HD95（2.0834）、ASD（0.2271）三指标上均达到全面最优的水平，验证了损失优化与卷积归纳偏置的协同增效作用。同时，本章指出 C3 相比 A3R3 的增量改善呈现边际递减效应，提示在高性能区间进一步的突破可能需要引入更根本性的方法变革。此外，本章坦诚讨论了测试集规模、实验口径限制及负向实验价值等方法论问题，为第6章的总结与展望奠定了基础。
