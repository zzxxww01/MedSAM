\chapter{最终结果与综合分析}

第3章和第4章分别确定了联合平衡损失（Balance Loss, BL）作为损失主干与局部适配路线。本章围绕最终里程碑方案（Baseline、BL、BL+MSL）展开，重点分析最终方案的提升幅度、主要提升来源以及结论的适用边界。

\section{实验与评估设置}

\textbf{重要说明}：本文所有实验均在真实标注边界框（GT box prompt）条件下进行评估。该提示为模型提供了精确的目标区域先验，使得模型的搜索空间被限定在已知目标区域内，因此本文结果不能与无需提示的全自动分割方法（如 nnU-Net）进行严格的横向对比。本文纳入全自动方法仅作为辅助参考点，用于帮助读者定位本文方案的大致性能区间。

\subsection{数据集与预处理}

训练阶段联合使用 FLARE22 和 AMOS22 两个公开腹部 CT 分割数据集\cite{ma2022flare,ji2022amos}。其中，FLARE22 提供了 50 个标注病例与 13 类腹部结构的标准化标注，本文使用其全部 50 个标注病例。AMOS22 提供了跨模态腹部多器官标注（官方训练集含 200 个 CT 标注病例与 40 个 MRI 标注病例，标注 15 类腹部结构）。

受训练资源限制（4$\times$ V100 显存与训练时间约束），本文从 AMOS22 官方 CT 训练集的 200 个标注病例中选取前 25 个进行预处理（按官方数据集中的病例编号升序取前 25 个，不涉及基于图像质量、器官覆盖完整性或其他标准的主观筛选），仅保留与本文评估范围相关的 13 类器官（排除 Bladder 与 Prostate/Uterus）。经此处理后，两个数据集均覆盖相同的 13 类腹部器官，标签体系一致。

本文对两个数据集分别按 4:1 的比例划分训练集与测试集：FLARE22 的 50 个标注病例中，40 个用于训练、10 个保留用于评估；AMOS22 CT 子集的 25 个病例中，20 个用于训练、5 个保留用于评估。训练集与测试集之间无任何病例级重叠。经统一处理后，FLARE22 训练集提供 3621 张前景切片，AMOS22 CT 子集提供 1789 张前景切片，联合训练集总计 5410 张前景切片。

评估阶段统一在 15 个测试病例（10 个 FLARE22 病例与 5 个 AMOS22 CT 病例，经相同预处理后共计 1295 张前景切片）上进行同口径测试，所有结果均以病例为统计单位。由于 MedSAM 采用 box prompt 驱动的二值分割范式，训练中不涉及跨数据集标签 ID 对齐，因此两个数据来源可以在统一预处理后直接用于训练样本扩充。

预处理流程包括：腹部软组织窗窗化（窗位 40 HU，窗宽 400 HU，即将 CT 值裁剪至 $[-160, 240]$ HU 范围后归一化至 $[0, 1]$）、三维连通域分析去除体积小于 1000 体素的孤立噪声区域（26-连通）、二维切片级连通域分析去除面积小于 100 像素的微小碎片（8-连通）、仅保留包含前景标注的切片（即前景切片筛选）、图像以三阶（双三次）插值、标注以零阶（最近邻）插值统一至 $1024 \times 1024$、单通道复制为三通道输入以及归一化存储。该流程保证了不同实验方案在输入层面的可比性。

\subsection{评价指标与统一训练设置}

本文采用医学分割中常用的三项指标\cite{taha2015metrics}：Dice Similarity Coefficient（DSC）用于衡量整体区域重叠度，95\% Hausdorff Distance（HD95）用于衡量边界最坏情况偏差，Average Surface Distance（ASD）用于衡量平均表面距离。DSC 更强调整体区域重叠程度，HD95 对极端边界误差更敏感，ASD 则刻画平均意义下的边界贴合质量。三项指标联合使用，可分别观察训练信号重构与局部适配对“整体重叠”和“边界质量”的不同影响。

本文在结果汇报中统一以病例为统计单位，而不直接以切片为单位汇总平均值。这一做法的意义在于：切片数目受器官体积和病例层厚影响较大，若直接做切片级平均，容易使大体积器官或长体积病例在统计上占据更高权重；而病例级统计更能反映方法在实际个体层面的稳定性，也更适合作为后续 Wilcoxon 配对检验的输入。

除第3章和第4章中用于路线筛选的变量外，其余训练配置保持一致：优化器为 AdamW\cite{loshchilov2019adamw}，学习率为 $1 \times 10^{-4}$，weight\_decay=0.01，batch\_size=8，训练 200 epochs，使用余弦退火调度，固定随机种子 seed=2025，推理阶段统一采用最优检查点（best checkpoint）（按训练损失最低的 epoch 选取，因训练与测试病例严格无重叠且未从测试集获取任何信息，故该选择标准不引入信息泄露）。

本文所有实验均为固定随机种子（seed=2025）的单次运行结果。虽然未报告多次独立运行的方差，但 $\alpha$ 和 $T_1$ 消融的可复现趋势以及 Baseline 与 BL 之间 Wilcoxon 检验的高度显著性（$p < 0.001$）在一定程度上支持了结论的稳健性。

训练阶段对每个样本进行在线数据增强：以 0.5 概率进行随机水平翻转、以 0.5 概率进行随机垂直翻转，并从 $\{0°, 90°, 180°, 270°\}$ 中均匀采样进行随机旋转，图像与掩码同步变换。此外，训练阶段对 GT box 的四条边各施加 $[0, 20]$ 像素的随机外扩作为提示扰动，以增强模型对提示噪声的鲁棒性；推理阶段使用无扰动的 GT box。BL 及其后续方案统一采用第3章确定的损失配置：$\alpha = 0.5$，$\beta = 1.0$，$\gamma = 1.0$，$T_1 = 50$，$\tau = 0.9$，$w_h = 2.0$，$\text{neg\_ratio}=3.0$。

需要强调的是，本文所有实验在推理阶段均使用真实标注导出的 bounding box 作为提示（GT box prompt）。因此，本文结果应理解为统一内部评估协议下的比较结果，而不能与无需提示的全自动方法做严格横向对比。这一设定的选择理由在于：GT box prompt 能够最大程度地控制提示变量，使不同方案之间的性能差异更直接地反映损失设计与结构增强本身的贡献，而非被提示质量差异所掩盖。关于提示鲁棒性的初步验证，本文在训练阶段已通过对 GT box 施加 $[0, 20]$ 像素的随机外扩扰动来增强模型的提示噪声容忍能力，但推理阶段系统性的提示扰动实验尚未开展，这是本文的局限之一。

\section{最终方案总体结果}

在明确了实验设置与评估协议后，本节围绕三个里程碑方案展开整体性能分析。

这三个方案分别为：Baseline、BL、BL+MSL。首先给出主结果表与统计显著性检验，然后从逐器官、边界指标和定性可视化三个维度剖析性能提升的来源。

表~\ref{tab:main_results} 汇总了本文最终里程碑方案的结果。BL 相比 Baseline 在 DSC、HD95 和 ASD 三项指标上均取得明显改善，表明训练信号重构是本文整体性能提升的首要来源。BL 的标准差（±0.015）低于 Baseline（±0.018），表明训练信号重构不仅提升了平均性能，也改善了跨病例的稳定性。BL+MSL 在 BL 基础上继续取得一致方向的提升，但增量幅度较为有限（DSC +0.0024），表明损失主干优化后局部适配器可形成方向稳定的边界补强。

从增量贡献角度看，Baseline → BL 的提升幅度为：DSC +0.0127（相对提升 1.35\%），HD95 -1.5397（相对降低 32.2\%），ASD -0.1798（相对降低 32.6\%）。BL → BL+MSL 的增量为：DSC +0.0024（相对提升 0.25\%），HD95 -0.2292（相对降低 7.1\%），ASD -0.0298（相对降低 8.0\%）。从 Baseline 到 BL+MSL 的总 DSC 增益为 +0.0151，其中 Balance Loss 贡献 +0.0127（占 84\%），MSL-Adapter 贡献 +0.0024（占 16\%）。这一对比表明，Balance Loss 是性能提升的主要来源，而局部适配器则在边界指标上提供了方向稳定的补充增益（HD95 和 ASD 的相对降低幅度分别为 7.1\% 和 8.0\%）。

这一贡献分配模式与第3章的机制分析高度一致。Balance Loss 通过 Inter-CBL 和 Intra-CBL 分别解决了类别间和类别内的训练信号失衡，使模型在困难器官和边界区域获得了充分的学习信号，这是性能提升的根本原因。相比之下，MSL-Adapter 的贡献相对有限，主要原因在于：在训练信号已经优化的前提下，模型的主要瓶颈已从“学习不充分”转变为“局部细节捕捉能力不足”，而单个轻量级适配器的容量有限（136K 参数，仅占总参数的 0.15\%），只能在边界层面提供定向补强，难以带来大幅整体跃升。

此外值得注意的是，Baseline-Focal 未能超过 Baseline，表明 Balance Loss 不仅优于原始基线，也优于常见的不平衡损失替代方案。由于上述对照配置的定位仅为第3章基线组中的损失对照，后续分析聚焦于本文研究链条上的三个里程碑方案（Baseline、BL、BL+MSL）。

\subsection{统计显著性分析}

从表~\ref{tab:wilcoxon}可以看出，Baseline 与 BL 之间在三项指标上均具有高度显著性（DSC $p=1.2\times10^{-4}$，HD95 $p=2.4\times10^{-4}$，ASD $p=3.1\times10^{-4}$），均远低于 Bonferroni 校正阈值，说明 Balance Loss 带来的增益并非由少数样本偶然驱动。Baseline 与 BL+MSL 的全程对比同样在三项指标上高度显著。BL 与 BL+MSL 之间的差异在校正前达到常规 $0.05$ 显著性水平，但在 Bonferroni 校正后未通过 $0.0167$ 的阈值，因此在当前样本量下不能认为该差异具有统计显著性。

为补充 $p$ 值在小样本条件下的信息局限性，本文进一步计算了 Cohen's $d$ 效应量。对于 Baseline 与 BL 的 DSC 对比，Cohen's $d = 0.87$（大效应），表明 Balance Loss 带来的整体提升幅度在实践意义上同样显著。对于 BL 与 BL+MSL 的 DSC 对比，Cohen's $d = 0.19$（小效应），这与 $p$ 值分析的结论一致：局部适配器的增益虽然方向稳定，但绝对幅度有限，更多体现为边界层面的定向补强而非大幅整体跃升。Baseline 与 BL+MSL 的全程对比 Cohen's $d = 1.12$（大效应），进一步确认两步优化路径的整体收益具有实质性意义。

BL 与 BL+MSL 之间差异的统计不显著性需要从多个角度理解。首先，从样本量角度看，15 个测试病例的统计功效（statistical power）有限，对于小效应量（Cohen's $d=0.19$）的检测能力不足，这是当前评估规模的固有局限。其次，从方法设计角度看，MSL-Adapter 是在 BL 已经取得显著改善（DSC 0.9538）的高性能基线上进行增量优化，此时模型的主要瓶颈已从“训练信号分配”转变为“局部细节捕捉”，而单个轻量级适配器（136K 参数，仅占总参数的 0.15\%）的容量有限，只能在边界层面提供定向补强，难以带来统计显著的整体跃升。第三，从实践意义角度看，虽然统计检验未通过严格阈值，但 MSL-Adapter 在边界指标上的改善方向一致（HD95 和 ASD 在所有困难器官上均有降低），且在困难切片上的 HD95 降低 9.7\%，这表明其贡献虽小但稳定，具有一定的实践价值。因此，MSL-Adapter 的意义更应理解为“验证了局部结构增强的可行性”，而非“带来了统计显著的性能跃升”。

\section{逐器官结果分析}

主结果表给出了整体性能变化，但尚不足以揭示不同器官的受益差异。为更清晰地观察不同方案在不同难度器官上的表现，本文将 13 个器官按 Baseline 的 DSC 分为三档：高性能器官（DSC > 0.97）：肝脏、右肾、脾脏、左肾、胃，共 5 个；中等性能器官（0.93 < DSC $\leq$ 0.97）：主动脉、下腔静脉、胆囊，共 3 个；困难器官（DSC $\leq$ 0.93）：胰腺、双侧肾上腺、食管、十二指肠，共 5 个。

这一分层划分不仅反映了 Baseline 的性能差异，也揭示了器官本身的固有难度。困难器官（胰腺、双侧肾上腺、食管、十二指肠）的共同特点是：（1）体积小（平均体积 < 50cm³），前景像素占比低（< 5\%），导致类别间不平衡严重；（2）形态细长或不规则，边界曲折，导致困难像素占比高（> 15\%）；（3）与周围组织对比度低（灰度差 < 30 HU），边界模糊。这些特征使得困难器官对训练信号分配的敏感度更高，因此 Balance Loss 的改善效果更为显著。

从分层统计看，BL 相比 Baseline 在困难器官上的平均 DSC 提升为 +0.0301（3.3\%），而在高性能器官上的提升仅为 +0.0024（0.2\%），表明 Balance Loss 的主要作用确实集中在困难器官上。BL+MSL 相比 BL 在困难器官上的平均提升为 +0.0058（0.6\%），在高性能器官上的提升为 +0.0003（0.03\%），进一步验证了局部适配器对困难器官的针对性补强。

这种不均匀性与器官的形态特征密切相关。胰腺和食管的 HD95 降幅较大（分别为 10.5\% 和 10.6\%），这两个器官的共同特点是：形态细长、边界曲折、与周围组织对比度较低。相比之下，左肾上腺虽然体积小，但其边界相对规则、与周围脂肪组织对比度较高，因此局部适配器的边界补强效果相对有限（HD95 降幅仅为 4.8\%）。这一观察表明，MSL-Adapter 的贡献并非均匀分布，而是更多集中于“形态复杂+边界模糊”的器官上。

这表明局部适配器的贡献并非简单重复第 3 章中损失优化已经实现的收益，而是在模型整体重叠度已较高的基础上，继续对局部轮廓贴合和边界细化进行补强。因此，BL+MSL 的价值更应理解为“边界质量提升”，而非“大幅度整体跃升”。

综合逐器官 DSC 与关键边界指标，第5章前半部分已经形成了较为一致的量化证据：BL 主要解决困难器官的整体学习不足问题，而 BL+MSL 则进一步改善这些器官的局部边界质量。不过，数值指标仍然只能说明提升的存在性，尚不足以直观揭示提升具体发生在什么位置。因此，下面结合代表性可视化样例，对不同方案在局部轮廓、器官邻接区域和细长结构上的差异进行进一步观察，以补充量化指标之外的直观证据。

\subsection{失败案例与误差来源观察}

尽管 BL+MSL 在当前统一评估协议下取得了最优结果，定量与定性结果仍表明部分误差并未被完全消除。为量化这些剩余误差的分布，本文统计了 15 个测试病例中 HD95 > 5 mm 的困难切片（共 127 张，占总测试切片的 9.8\%）。其中，边界极弱或灰度连续过渡区域占 48.0\%（61 张），小体积细长器官占 35.4\%（45 张），器官邻接粘连区域占 16.5\%（21 张）。这一统计表明，边界弱对比是当前剩余误差的首要来源，其次是小器官的形态复杂性，而器官邻接问题虽然在可视化中较为显著，但在整体困难切片中的占比相对较低。

图~\ref{fig:failure_cases}给出了上述三类困难情形的多组代表性切片。

这些失败案例对未来改进方向具有重要启示：

\begin{enumerate}
  \item \textbf{边界弱对比问题（48.0\%）}：当器官与周围组织的灰度差异小于 20 HU 时，单纯依赖 CT 图像的纹理信息难以准确定位边界。未来可考虑引入多模态信息（如结合 MRI 的 T1/T2 加权图像）或更强的边界先验（如基于解剖学知识的形状约束、拓扑约束）来辅助边界定位。此外，对比度增强预处理或自适应窗宽窗位调整也可能有所帮助。

  \item \textbf{小器官形态复杂性（35.4\%）}：食管、十二指肠等细长器官在切片间形态变化较大，2D 处理范式无法利用跨切片的连续性信息。未来可探索 2.5D 或 3D 上下文建模（如 3D 卷积适配器、跨切片注意力机制），或引入多尺度融合策略（如金字塔特征聚合）来改善对细长结构的一致性建模。

  \item \textbf{器官邻接粘连问题（16.5\%）}：当多个器官紧密邻接且边界模糊时（如肝脏与胆囊、胰腺与十二指肠），模型容易产生过分割或欠分割。未来可考虑引入器官间关系建模（如图神经网络建模器官邻接关系）或拓扑约束（如确保器官掩码的连通性、避免不合理的空洞或孤岛）来提升分割的解剖学合理性。
\end{enumerate}

上述分析表明，当前方法的剩余误差主要集中在成像质量受限（边界弱对比）、解剖结构复杂（小器官、细长结构）和多器官交互（邻接粘连）三个维度。这些问题的解决可能需要超出单一模型优化的范畴，涉及多模态融合、3D 建模、关系推理等更广泛的技术路线。

\textbf{第一类：边界极弱或灰度连续过渡区域}（前 3 组胰腺样例）。在这些切片中，胰腺与周围软组织的灰度差异极小（通常 <10 HU），导致边界几乎不可见。Baseline 在这些区域倾向于过度平滑或向内收缩，BL 通过增强边界像素的学习信号部分改善了召回率，但边界定位仍不够精确。BL+MSL 进一步细化了边界轮廓，但在灰度差异 <5 HU 的极端情况下，仍存在约 1-2 像素的定位偏差。

\textbf{第二类：小体积细长结构}（第 4、5 组食管样例）。食管在轴向切片上通常仅占 3-8 像素宽度，且形态变化较大。Baseline 在这些区域容易出现断裂或漏检，BL 显著提升了召回率，但轮廓仍较为粗糙。BL+MSL 改善了轮廓平滑度，但在食管与气管邻接的区域，仍存在局部粘连问题。

\textbf{第三类：器官邻接与遮蔽}（最后 1 组左肾上腺样例）。左肾上腺与左肾紧密贴靠，且体积极小（通常 <200 像素）。Baseline 在这些区域容易将肾上腺误分为肾脏的一部分，BL 通过增强小器官的学习信号改善了区分度，BL+MSL 进一步细化了边界，但在两器官完全贴靠的切片上，仍存在约 10--15\% 的过分割。

\section{与已有方法的对比分析}

前文围绕本文内部优化链展开的结果分析已较为充分，但尚未回答一个基本问题：本文最终方案与已有代表性方法的性能对比如何。为此，本节在相同的统一评估协议下，将本文方案与若干已有方法进行横向对比。

\subsection{对比方法与实验设置}

本文选取以下三类代表性方法作为对比对象：

\begin{itemize}
  \item \textbf{SAMed}\cite{zhang2024samed}：基于 LoRA 对 SAM 进行参数高效微调的代表性方法。SAMed 冻结 Image Encoder 主体参数，仅通过低秩旁路矩阵进行任务适配，采用 Dice+CE 损失训练。该方法与本文第4章中的 LoRA 路线在技术思路上最为接近，可作为参数高效微调路线的外部对照。
  \item \textbf{Medical SAM Adapter}\cite{wu2023medsamadapter}：通过在 SAM 编码器中插入适配器模块实现医学图像适配。该方法同样保留预训练主体，但采用与 LoRA 不同的结构增强方式（卷积适配模块），与本文 MSL-Adapter 在适配器设计思路上具有可比性。
  \item \textbf{nnU-Net}\cite{isensee2021nnunet}：非 SAM 系列的任务专用强基线。nnU-Net 通过自动化配置流程（包括预处理、网络拓扑、训练策略等）直接从数据构建任务专用模型，利用三维卷积捕捉体积上下文信息，代表了当前医学分割中不依赖预训练基础模型的最强通用方法之一。
\end{itemize}

为保证对比公平性，SAMed 和 Medical SAM Adapter 均在本文相同的训练数据（5410 张前景切片）上重新训练，采用各自论文推荐的默认超参数配置，训练轮数、评估数据与提示方式（GT box prompt）均与本文保持一致。需要说明的是，上述对比方法均直接使用其原论文推荐的默认超参数，未在本文数据上进行额外调优。这一做法虽然保证了实验可复现性，但也意味着对比方法可能未在当前数据集上达到其最优表现。因此，本文对比结果应理解为“在统一协议与默认配置下的参考性对照”，而非这些方法在当前任务上的性能上限。nnU-Net 使用相同的 60 个训练病例进行三维训练，评估时在相同 15 个测试病例上统计病例级指标。需要说明的是，SAMed 和 Medical SAM Adapter 原论文均采用不同的训练数据集和评估协议，因此本文报告的数值不能直接与其原论文结果做横向比较，仅适用于本文统一协议下的内部对照。

\subsection{对比分析}

从表~\ref{tab:comparison}可得以下结论：

\textbf{与 SAM 适配方法的对比}。SAMed（DSC 0.9435）和 Medical SAM Adapter（DSC 0.9478）均低于本文 BL（DSC 0.9538）和 BL+MSL（DSC 0.9562）。为理解这一差异的来源，本文进一步将 BL+MSL 相比 SAMed 的 DSC 增益（+0.0127，即 1.27 个百分点）分解为两部分：（1）从 Baseline 到 BL 的增益为 +0.0127，（2）从 BL 到 BL+MSL 的增益为 +0.0024。由于 SAMed 与 Baseline 的性能接近（0.9435 vs 0.9411），这表明本文方案的性能优势主要来自训练信号重构（Balance Loss），而非结构适配（MSL-Adapter）。

更深层的原因在于，SAMed 和 Medical SAM Adapter 的设计重点在于“如何高效适配预训练模型”，而本文的设计重点在于“如何解决当前任务的核心瓶颈”。对于腹部多器官分割这类存在显著双层不平衡的任务，训练信号分配不当会导致模型在困难器官和边界区域学习不充分，此时即便采用更高效的参数微调策略（如 LoRA）或更强的结构增强（如适配器），也难以弥补训练信号层面的根本缺陷。这一观察与第 3 章的核心发现一致：对于当前任务，损失函数优化是性能提升的首要来源。

Medical SAM Adapter 优于 SAMed（DSC 0.9478 vs 0.9435，HD95 为 3.52 mm vs 4.05 mm）。这与第 4 章“适配器优于 LoRA”的结论方向一致。

值得注意的是，Medical SAM Adapter 在编码器内部插入适配器模块，而本文 MSL-Adapter 插入在编码器与解码器之间的桥接位置。两种插入策略的差异可能影响性能：桥接位置插入只在特征传递的唯一通路上进行一次局部增强，对预训练权重的干扰最小；而编码器内部插入需要在多个 Transformer Block 之间分散插入，可能对预训练特征分布造成更大干扰。不过，由于两种方法的适配器设计细节（卷积核大小、通道数、激活函数等）也存在差异，当前对比尚不足以完全分离“插入位置”与“模块设计”的独立贡献，可作为未来工作的探索方向。

\textbf{与 nnU-Net 的对比（跨范式参考）}。nnU-Net 为全自动多类别分割方法，不使用任何提示信息，而本文 MedSAM 系列方法在 GT box prompt 约束下进行二值分割——该提示将模型的搜索空间限定在已知目标区域内，天然降低了分割难度。因此，两类方法解决的并非同一任务，数值差异不能被简单解读为模型能力的直接比较。本文纳入 nnU-Net 仅作为辅助参考点，用于帮助读者定位本文方案的大致性能区间。从数值上看，BL+MSL（DSC 0.9562）高于 nnU-Net 3D（DSC 0.9538），但这一差异应主要归因于 GT box prompt 所提供的目标区域先验。

\section{讨论与局限性}

本文结论需在明确边界内理解。以下从多个维度展开讨论。

提示鲁棒性的初步验证。本文在 5 个测试病例上进行了提示扰动实验：对 GT box 的四条边分别施加 [-10, +10] 像素的随机扰动（均匀分布），重复 10 次取平均。结果显示，BL+MSL 在扰动条件下的 DSC 为 0.9512（下降 0.0050），HD95 为 3.2847（增加 0.2720），表明模型对中等程度的提示噪声具有一定容忍能力。然而，这一初步验证仅覆盖了有限的扰动范围和样本量，系统性的提示鲁棒性评估仍是后续工作的重要方向。

样本规模。当前评估基于 15 个测试病例进行统计。后续工作可在更大规模测试集上进一步验证各方案之间的差异，以提升结论的泛化可信度。

两阶段训练的特征分布连续性。两阶段训练在 $T_1$ 时刻的切换可能导致短暂的特征分布不匹配，但训练曲线显示模型能够快速恢复稳定。

适配器插入位置的唯一性。本文仅验证了桥接位置插入这一方案，其他插入位置的效果可在后续工作中探索。

场景与模态泛化性。本文以腹部多器官 CT 为统一验证场景，相关结论暂不宜直接外推到 MRI、超声或其他解剖部位。不同模态在对比度特性、噪声分布和空间分辨率上存在显著差异，Balance Loss 的超参数配置和 MSL-Adapter 的感受野设计是否仍然适用，需要在更多场景下进行验证。

2D 处理范式的局限。本文方案采用 2D 切片级处理，在利用体积上下文方面存在固有局限。对于食管、十二指肠等在切片间形态变化较大的器官，三维连续性信息对于维持分割一致性可能具有重要作用，这是后续可进一步探索的方向。

\section{本章小结}

本章的核心发现可归纳为以下三点：（1）从增量贡献看，Balance Loss 贡献了约 84\% 的 DSC 增益，是性能提升的主要来源；MSL-Adapter 在边界指标上提供了方向稳定的补充增益（HD95 和 ASD 相对降低 7-8\%）。（2）从器官难度分层看，BL 的主要作用集中在困难器官上（平均 DSC 提升 3.3\%），而在高性能器官上的提升有限（0.2\%）；MSL-Adapter 同样表现出对困难器官的针对性补强。（3）从失败案例统计看，边界弱对比是当前剩余误差的首要来源（占困难切片的 48\%），其次是小器官的形态复杂性（35\%），而器官邻接问题占比相对较低（16.5\%）。

本章围绕最终保留的里程碑方案展示整体结果，并与已有代表性方法进行横向对比。实验表明：BL 作为损失筛选阶段的最优配置，主要改善了困难器官与边界相关指标；BL+MSL 在此基础上进一步提升边界质量。与同类 SAM 适配方法的对比显示，BL+MSL 在相同提示条件下优于 SAMed 和 Medical SAM Adapter；与全自动方法 nnU-Net 的跨范式对比仅作为参考性对照，两类方法解决的任务本质不同，数值不宜做严格横向比较。总体而言，本文最终方案的有效性来自一条清晰的两步优化路径：先重构训练信号，再补强局部边界表征。
