\chapter{总结与展望}

\section{工作总结}

本文围绕 MedSAM 在腹部多器官 CT 分割任务中面临的两类关键问题——双重类别不平衡与空间局部高频特征先验不足——开展了系统性研究，提出了两项核心创新（Balance Loss 与 LG-Adapter）并辅以关键消融验证（LoRA 实验），通过完整的消融路径进行了严格的实验验证。主要工作总结如下：

\begin{enumerate}
  \item \textbf{构建联合平衡损失框架 Balance Loss（第3章，A3R3）}。针对医学图像分割中前景与背景之间、不同器官类别之间的双重不平衡问题，本文设计了由 Inter-CBL（类别间平衡损失）和 Intra-CBL（类别内难度加权损失）联合构成的 Balance Loss 框架。Inter-CBL 通过对齐困难背景与前景的样本数量来抑制背景梯度主导，Intra-CBL 通过阈值机制对边界困难像素施加更高权重以强化边界学习。同时，本文引入两阶段训练策略以缓解冷启动噪声。通过严格的单变量剥离控制变量实验（A3R2/A3R3），本文将原始 Balance Loss 退化的根因定位为 Inter-CBL 权重过大（H1 通过、H2 否定），最终确定 $\alpha=0.5$ 的 A3R3 为最优配置。该配置将基线 DSC 从 0.9407 提升至 0.9596，HD95 降低 53.4\%（4.83$\rightarrow$2.25），ASD 降低 54.2\%（0.54$\rightarrow$0.25），全面验证了损失层面改进的有效性。

  \item \textbf{揭示低秩参数高效微调在复杂医学域的局限性（第4章，C2）}。本文通过实施 LoRA（$r=4$）冻结主干微调实验，在同口径评估中观察到 DSC 从 0.9596 降至 0.8796（降幅 8.3\%）、HD95 劣化 244.6\%、ASD 劣化 304.5\% 的严重性能下降。该消融实验表明：在 FLARE22 这类高异质性、多器官的腹部 CT 分割任务中，仅依靠低秩（$r=4$）LoRA 旁路对 Q 投影层进行参数高效微调，无法替代 Image Encoder 的全参数更新。模型必须在高维特征空间中进行深层非线性重塑，才能适配 13 类形态差异巨大的腹部器官。需要指出，近期研究\cite{wu2023medsamadapter}表明 LoRA 与空间适配器联合使用可能部分缓解该问题，因此 C2 的负向结论应限定在当前实验条件下。

  \item \textbf{设计局部-全局多尺度边缘适配器 LG-Adapter（第4章，C3）}。基于 C2 消融实验揭示的全参微调必要性，本文进一步针对 ViT 编码器缺乏局部归纳偏置的问题，提出了轻量级的 Local-Global Adapter。该模块通过双路径深度可分离卷积（标准 $3\times3$ + 膨胀 $3\times3$，$d=2$）提取多尺度局部特征，经逐点卷积融合后通过残差连接注入主管线，以仅 136,448 个额外参数（占总参数的 0.15\%）有效弥补了 ViT 对高频边缘特征的固有忽视。C3 方案最终在 10 例测试集上（GT box prompt 条件）达到 DSC=0.9620、HD95=2.0834、ASD=0.2271 的三指标全面最优，相比基线分别实现了 2.1 个百分点的 DSC 绝对提升、56.9\% 的 HD95 降低和 57.8\% 的 ASD 降低。
\end{enumerate}

\subsection{消融路径的方法论贡献}

本文的实验设计遵循了严格的"控制变量法"原则，从 A0 基线出发，经 A1/A2 的单组件验证、A3 的退化发现与 A3R1/R2/R3 的假设检验、C2 的 LoRA 消融，最终到达 C3 的完整方案。该消融路径的特色在于：

\begin{enumerate}
  \item \textbf{正向验证与反向证伪相结合}：不仅通过 A3R3、C3 等正向实验验证了方法的有效性，还通过 A3（退化）、C1（Attention 退化）、C2（LoRA 退化）等负向实验划定了方法的适用边界。
  \item \textbf{竞争假设驱动的因果推断}：针对 A3 退化现象，本文提出了两个竞争假设并通过单变量剥离实验（R2/R3）进行严格验证，避免了多变量同时调整导致的混淆效应。
  \item \textbf{同口径可比评估}：全部实验均在 FLARE22 数据集的 10 例独立测试集上进行评估，使用相同的训练超参数（AdamW, lr=$10^{-4}$, 200 epochs），保证了结论的可比性。
\end{enumerate}

\section{研究不足}

\begin{enumerate}
  \item \textbf{对真实标注框提示的依赖}：本文所有实验均使用真实标注导出的 bounding box 作为提示（GT box prompt），这为模型提供了显著的空间先验优势。在实际临床场景中，真实标注框不可获得，因此需要引入自动器官检测模块（如基于 nnDetection 或 YOLO 系列的检测器）生成候选框提示，这将不可避免地引入检测噪声（框偏移、漏检等），可能导致分割性能的下降。本文方法在带噪声提示条件下的鲁棒性尚未验证，是未来过渡到全自动分割流水线的关键技术瓶颈。
  \item \textbf{跨模态与跨部位泛化性有待验证}：本文所有实验聚焦于 FLARE22\cite{ma2022flare}的腹部多器官 CT 数据。将 Balance Loss 和 LG-Adapter 推广至 MRI、超声等其他成像模态，以及脑部、胸部等其他解剖部位，需要进一步的跨域适配研究。不同模态在噪声特性、对比度分布和空间分辨率上存在显著差异，当前方法的超参数配置（如 Intra-CBL 的阈值 $\tau$、Inter-CBL 的权重 $\alpha$）是否具有跨域鲁棒性，尚需验证。
  \item \textbf{测试集规模与统计显著性}：全部实验基于 10 例测试集进行评估。样本量偏小导致个别 outlier 对指标影响显著。本文未进行 k-fold 交叉验证或 bootstrap 置信区间估计，方案间的细微差异（如 C3 vs A3R3 的 HD95 差距）可能缺乏统计显著性。此外，测试数据来自单一中心、单一扫描协议，无法充分验证跨中心泛化能力。
  \item \textbf{LG-Adapter 增量改善的边际性}：C3 相比 A3R3 的提升幅度（DSC +0.25\%，HD95 $-7.4\%$）呈现明显的边际递减效应，表明在 DSC 超过 0.96 的高性能区间，单层卷积适配器的架构增益趋于饱和。未来工作可探索多层插入策略（如在 ViT 编码器的多个 Transformer Block 后分别插入适配模块）或与 LoRA 等参数高效微调方法联合使用，以期获得更大幅度的性能突破。
  \item \textbf{推理效率的优化空间}：尽管 LG-Adapter 本身的计算开销可忽略不计（$<$1 ms/样本），但 MedSAM 整体管线（ViT-Base 编码器 + Mask Decoder）的推理成本仍然较高。在对实时性要求严格的临床部署场景中，模型压缩和加速仍是需要解决的工程问题。
\end{enumerate}

\section{未来展望}

基于本文的研究成果和已识别的不足，后续可从以下方向继续推进：

\begin{enumerate}
  \item \textbf{三维体积分割扩展}：将 LG-Adapter 的多尺度卷积从 2D 扩展到 3D，与 nnU-Net 3D\cite{isensee2021nnunet}或 SAM 2\cite{ravi2024sam2}的视频分割框架结合，利用帧间立体时序信息提升小器官（如肾上腺、十二指肠）的分割精度。三维膨胀卷积可在体积数据上提供更丰富的轴向上下文，有望进一步缓解 2D 切片分割中的层间不连续性问题。
  \item \textbf{混合参数高效微调策略}：探索更精细的分层微调方案，例如在 ViT 的浅层（第 1--6 层）使用 LoRA 冻结（保留通用视觉先验），在深层（第 7--12 层）开放全参微调并插入 LG-Adapter（进行医学域特化），以期在特征空间重塑能力与显存效率之间找到更优的 Pareto 解。该方向可结合本文 C2 消融实验的发现，通过逐层解冻实验系统性地研究"冻结深度"与"性能退化"之间的量化关系，例如以 2 层为步长从深到浅逐步解冻，绘制 DSC-冻结层数的退化曲线。
  \item \textbf{自适应损失权重调节}：当前 Balance Loss 的超参数（$\alpha$、$\tau$、$w_h$ 等）通过网格搜索确定，缺乏自适应性。未来可探索基于训练动态的自适应权重调节策略，例如根据当前 epoch 的类别不平衡程度和模型置信度分布自动调整各损失分量的权重，以减少手动调参负担并提升跨数据集的泛化能力。
  \item \textbf{多中心外部验证与统计评估}：在更大规模的多中心数据集（如 AMOS 2022、TotalSegmentator）上进行外部验证，并采用 bootstrap 置信区间和 Wilcoxon 符号秩检验等统计方法，为方法结论提供更严格的统计保障。
  \item \textbf{临床交互式分割系统}：将 MedSAM 的提示式交互优势与本文的改进方法相结合，构建面向临床工作流的半自动分割系统。通过视觉-语言模型自动检测分割结果中的异常区域并生成修正提示，实现人机协作的精细化分割闭环。
  \item \textbf{从 GT box prompt 到自动提示的过渡}：本文所有实验依赖真实标注框提示，未来应研究在自动检测框（如基于预训练器官检测器生成的 noisy box prompt）条件下方法的鲁棒性。具体可通过向 GT box 添加随机偏移（如 $\pm$5--20 像素的坐标扰动）来模拟检测噪声，系统性地评估 Balance Loss 和 LG-Adapter 在带噪声提示条件下的性能退化曲线，为全自动部署提供工程指导。
\end{enumerate}
