\chapter{总结与展望}

\section{工作总结}

本文以 MedSAM 为基座，围绕医学分割任务中的两个关键问题展开研究：一是训练信号在前景/背景与困难/易分像素之间分配不均，二是 ViT 编码器对局部边界与细粒度结构的表征能力不足。论文以腹部多器官 CT 为统一验证场景，通过问题驱动的方式构建针对 MedSAM 的优化链，依次回答何种损失配置更合适、何种适配路线更值得保留，以及最终方案提升了哪些方面。

围绕这一目标，本文的主要工作可概括为以下三个方面：

\begin{enumerate}
  \item \textbf{完成了 Balance Loss 的设计与配置筛选。} 针对医学分割中的前景/背景失衡与困难像素学习不足问题，本文设计了由 Inter-CBL、Intra-CBL 和两阶段训练策略构成的 Balance Loss，并通过统一比较、竞争假设验证和参数敏感性分析，最终确定 A3R3 作为后续统一采用的损失主干。实验表明，该配置相较基线在当前评估协议下带来了稳定增益，说明训练信号重构是本文整体性能提升的首要来源。

  \item \textbf{完成了多条微调/适配路线的比较，并保留局部适配方案。} 在固定 A3R3 后，本文进一步比较了 Cross-Attention 融合、冻结主干 LoRA 不同秩设置和局部适配路线。结果显示，Cross-Attention 未带来稳定收益，LoRA 虽随秩增大有所改善，但整体仍难以替代开放主干的特征适配能力。相比之下，局部适配器在较小额外参数开销下带来了更稳定的边界增益，因此被保留为最终结构增强方案。

  \item \textbf{形成了“先筛选、后展示”的分阶段证据链。} 本文将第3章组织为损失策略选择，第4章组织为微调/适配路线选择，第5章则专门展示最终保留方案的总体结果、逐器官表现、边界分析和局限性讨论。通过这种组织方式，A3 退化、Cross-Attention 回落和 LoRA 退化等负向结果不再只是零散实验，而成为研究路线收敛的重要证据。
\end{enumerate}

在当前统一评估协议下，最终方案 C3 取得 DSC 0.9620、HD95 2.0834、ASD 0.2271。逐器官结果与边界指标表明，本文两步优化路径具有清晰的分工：Balance Loss 主要改善困难器官和边界区域的训练信号分配，局部适配器在此基础上进一步补强边界细化能力。本文更注重的是问题定义的准确性、路线筛选的充分性与最终证据链的闭合性，而非单纯依赖模块命名体现贡献。

从整体研究完成度而言，本文的价值不仅在于保留了一个性能更优的组合方案，更在于较为清晰地回答了两个过程性问题：第一，MedSAM 在当前任务中的主要短板首先体现在训练信号层还是结构层；第二，在训练信号优化之后，是否仍有必要进行结构补强，以及应优先补在何处。正因为第3章与第4章分别完成了这两个问题的回答，第5章中的最终结果才不仅是最优数值展示，而是完整研究链条的收束。

从论文写作方式而言，本文尝试体现一种与基础模型适配研究相匹配的组织思路：面对强预训练基座，与其将多个模块平行堆叠并将所有结果均列为贡献，不如先识别主要矛盾，再通过连续比较逐步排除不合适的路线。A3 原始配置退化、Cross-Attention 回落以及冻结主干 LoRA 受限等结果正是在这一逻辑下被保留为关键排除性证据。最终方案并非预设的正确答案，而是在围绕具体问题不断收敛后保留的结论。

\section{研究不足}

尽管本文在当前实验设置下取得了较为一致的结果，仍存在以下局限：

\begin{enumerate}
  \item \textbf{对 GT box prompt 的依赖。} 本文所有实验均使用真实标注导出的 bounding box 作为提示。这一设定有利于控制变量并保证内部比较公平，但与真实临床应用中的全自动或弱监督设置仍存在明显差异。未来需要进一步验证方法在自动检测框或带噪声提示条件下的稳健性。
  \item \textbf{评估样本规模有限。} 全部结果基于 40 个 FLARE22 预处理病例进行统计。虽然本文通过逐病例 Wilcoxon 检验增强了结果可信度，但更大规模、跨中心和外部测试集上的验证仍然必要。
  \item \textbf{结论范围仍局限于当前验证场景。} 本文以腹部多器官 CT 为统一验证场景，尚未验证 Balance Loss 与局部适配思路在 MRI、超声或其他解剖部位上的迁移效果，因此不宜将当前结论直接外推为广义的通用医学分割结论。
  \item \textbf{最终结构增益具有边际性。} 相比 A3R3，C3 的整体提升幅度有限，说明在高性能区间内，单个轻量级局部适配器更多带来边界层面的稳定补充，而非大幅整体跃升。这也提示后续研究可进一步探索更强的结构补强或更丰富的鲁棒性验证。
\end{enumerate}

上述局限并非彼此割裂，而是共同界定了本文结论的适用边界。GT box prompt 依赖意味着当前结果更适合作为统一内部比较依据；样本规模与验证场景的限制意味着本文更适合被理解为定向优化研究；最终结构增益的边际性则提示，在强基线条件下后续改进需要更有针对性的验证。

若从研究方法角度总结这些不足，当前最需要补强的并非更多实验数量，而是更丰富的验证维度。后续工作不应仅在同一协议下继续提升指标，而应重点回答：当提示存在扰动时方法是否稳定、当数据来源变化时结论是否成立、当评价对象从内部测试转向外部数据时收益能否保持。只有在这些维度上继续推进，本文两步优化路径才能从当前场景有效进一步发展为更广范围内具有参考价值。

\section{未来展望}

基于本文的研究过程与当前局限，后续工作可从以下方向继续推进：

\begin{enumerate}
  \item \textbf{补充更完整的损失对照与稳健性验证。} 例如进一步与 Tversky、Focal-Tversky 等不平衡损失比较，并结合不同训练数据比例、不同阶段切换点或更多统计评估手段，增强对 Balance Loss 有效性的论证。
  \item \textbf{扩展局部适配器的结构验证。} 可进一步比较不同插入位置、不同分支结构、是否使用多层插入及其与 LoRA 等 PEFT 方案的组合，以更系统地分析局部适配路线的设计空间。
  \item \textbf{开展 prompt 鲁棒性与自动提示实验。} 在 GT box 扰动、自动检测框或提示噪声条件下验证方法性能，有助于推动本文工作从内部统一评估走向更接近实际应用的场景。
  \item \textbf{验证跨数据集和跨模态泛化性。} 在更多腹部 CT 数据、外部测试集，乃至 MRI 等其他模态上开展迁移验证，将有助于判断本文提出的优化思路是否具有更广泛的适用性。
  \item \textbf{结合失败案例开展误差来源分析。} 对边界模糊、器官邻接、体积过小等典型失败情形进行分层研究，可进一步提升对问题本质的理解，并为下一步方法改进提供更具体的方向。
\end{enumerate}

从未来工作的优先顺序而言，首先值得推进的并非继续增加零散模块，而是围绕本文已识别的关键边界条件进行系统验证。例如，若 prompt 鲁棒性实验表明 A3R3 与 C3 在提示扰动下仍保持相对优势，则本文关于训练信号重构与局部边界补强的结论将更接近真实应用场景；若跨数据集或跨模态验证显示类似趋势，则研究价值也将从单一内部评估扩展至更具代表性的迁移问题。

与此同时，本文的两条方法主线之间也仍存在进一步联动的空间。当前研究采取的是先锁定损失主干、再筛选结构路线的顺序，这有利于形成清晰证据链；但在更深入的后续研究中，也可以进一步探讨两者之间是否存在更细致的耦合关系，例如不同局部适配结构是否需要配套不同困难像素权重策略、不同提示噪声水平下损失设计与结构设计的主导作用是否会发生变化等。这些问题若能继续展开，将有助于把本文目前形成的“阶段性优化链”进一步提升为更系统的任务适配方法论。

从更长远的角度看，本文未来工作的价值还不仅在于把某一条实验曲线继续向上推动，更在于逐步建立一种适用于医学基础模型研究的评估逻辑：先在统一协议下识别真正有效的改进来源，再通过鲁棒性、泛化性和失败案例分析判断这些来源是否具有更广泛的稳定意义。如果这种评估逻辑能够持续落实，那么后续研究即便面对不同数据集、不同模态或不同提示条件，也仍然可以沿着“先确认主要短板，再寻找最匹配的最小有效修正”这一思路继续推进。

总体而言，本文的价值主要体现在：围绕 MedSAM 在医学分割中的两个关键短板，构建了一条由损失筛选到路线筛选、再到最终验证的完整研究链条。未来若能在鲁棒性、泛化性与更丰富的实验验证方面继续推进，该研究路线仍具有较大的拓展空间。

从更一般的意义上看，本文的研究也反映出基础模型时代医学图像分割研究的一个重要特征：真正决定工作说服力的往往不只是是否提出了全新模块，而在于是否准确识别了强基线仍未解决的问题、是否通过连续比较排除了不合适的增强路线，以及最终方案是否与问题本身保持一致。就此而言，本文虽立足于 MedSAM 和腹部多器官 CT 场景，但其围绕明确短板建立逐层收敛证据链的研究组织方式，仍对类似的医学基础模型适配研究具有参考意义。
