\chapter{总结与展望}

\section{工作总结}

本文以 MedSAM 为基座，围绕医学分割任务中的两个关键问题展开研究：一是训练信号在前景/背景与困难/易分像素之间分配不均，二是 ViT 编码器对局部边界与细粒度结构的表征能力不足。论文以腹部多器官 CT 为统一验证场景，通过问题驱动的方式构建针对 MedSAM 的优化链，依次回答何种损失配置更合适、何种适配路线更值得保留，以及最终方案提升了哪些方面。

围绕上述目标，本文的主要工作可概括为以下三个方面：

\begin{enumerate}
  \item 识别并形式化了提示式二值分割场景下的双层不平衡问题结构，并据此完成 Balance Loss 的设计与配置筛选。本文指出，当前任务的训练信号失衡体现在类别间（前景/背景）与类别内（困难/易分像素）两个层面，需要分别设计独立机制。Focal Loss 等统一连续调制策略在当前任务中未能带来提升，佐证了这一判断。基于这一问题建模，本文设计了由 Inter-CBL、Intra-CBL 和两阶段微调策略构成的 Balance Loss，并通过统一比较、竞争假设验证和参数敏感性分析，最终确定 BL 作为后续统一采用的损失主干。实验表明，该配置相较基线在当前评估协议下带来了稳定增益，说明训练信号重构是本文整体性能提升的首要来源。

  \item 完成了多条微调/适配路线的比较，并保留局部适配方案。在固定 BL 后，本文进一步比较了 Cross-Attention 融合、冻结主干 LoRA 不同秩设置和局部适配路线。结果显示，Cross-Attention 未带来稳定收益，LoRA 虽随秩增大有所改善，但整体仍难以替代开放主干的特征适配能力。相比之下，局部适配器在较小额外参数开销下（增加 0.14M 参数，占总参数的 0.15\%）在边界指标上取得了一致的改善：HD95 从 3.2419 降至 3.0127（降低 7.1\%），ASD 从 0.3716 降至 0.3418（降低 8.0\%）。BL+MSL 在边界指标上取得了一致的改善，MSL-Adapter 在损失优化基础上提供了稳定的局部边界补强，支持了损失优化之后局部结构增强仍是可行改进方向这一判断。

  \item 通过系统消融与路线对比，建立了当前任务中不同优化策略的适用性判据。Focal Loss 未能改善、BL-$\alpha$1.0 退化、Cross-Attention 回落和 LoRA 受限等负向结果不仅作为路线收敛的排除性证据，也为类似提示式医学分割任务中的策略选择提供了参考。
\end{enumerate}

在当前统一评估协议下，最终方案 BL+MSL 取得 DSC 0.9562、HD95 3.0127、ASD 0.3418。从数值层面看，HD95 降低了约 37\%，边界质量得到明显改善。逐器官结果与边界指标表明，本文两步优化路径具有清晰的分工：Balance Loss 主要改善困难器官和边界区域的训练信号分配，是本文整体性能提升的首要来源；局部适配器在此基础上提供了方向稳定的边界补强。

本文的核心价值体现在三个方面：第一，明确了 MedSAM 在当前任务中的主要瓶颈是训练信号分配而非结构设计，为类似提示式医学分割任务提供了优化方向参考；第二，支持了在训练信号优化后，局部结构增强是可行的改进方向这一判断，为后续适配器设计提供了实证参考；第三，通过系统消融与路线对比，建立了当前任务中不同优化策略的适用性判据，Focal Loss 未能改善、BL-$\alpha$1.0 退化、Cross-Attention 回落和 LoRA 受限等负向结果为类似任务中的策略选择提供了排除性证据。

\section{研究边界与未来方向}

本文在当前实验设置下取得了较为一致的结果。为进一步提升方法的泛化能力和实用价值，后续工作可在以下方向继续深化：

\begin{enumerate}
  \item 提示鲁棒性验证有待深化。本文目标场景为交互式临床分割工作流（医生先提供粗定位框，模型完成精细分割），所有实验均使用真实标注导出的 bounding box 作为提示，以控制提示变量并保证内部比较公平。训练阶段的 $[0, 20]$ 像素随机外扩提供了初步的提示鲁棒性验证。未来需要系统性地评估方法在自动检测框（如基于 nnDetection 或 YOLO 的器官检测输出）或更大扰动幅度条件下的稳健性，以判断本文优化路径在实际提示噪声下是否仍保持相对优势。这一验证对于判断方法在真实临床工作流中的适用性至关重要。

  \item 评估样本规模可进一步扩展。全部结果基于 15 个测试病例进行统计。后续可进一步在更大规模外部测试集上开展验证，以提升结论的泛化可信度。

  \item 结论范围聚焦于当前验证场景。本文以腹部多器官 CT 为统一验证场景，尚未验证 Balance Loss 与局部适配思路在 MRI、超声或其他解剖部位上的迁移效果，因此不宜将当前结论直接外推为广义的通用医学分割结论。

  \item 2D 处理范式的局限。本文采用 2D 切片级处理，未利用体积上下文信息。对于食管、十二指肠等在切片间形态变化较大的器官，三维连续性信息可能有助于提升分割一致性。

  \item 单次运行的局限。本文所有实验均为固定随机种子（seed=2025）的单次运行结果，未报告多次独立运行的方差，这可能影响结论的稳健性评估。
\end{enumerate}

上述局限共同界定了本文结论的适用边界。后续工作应重点在提示鲁棒性、跨数据集泛化性等维度进行系统验证。

\section{未来展望}

基于本文的研究过程与当前局限，后续工作可从以下方向继续推进：

\begin{enumerate}
  \item 系统性的 prompt 鲁棒性验证。在 GT box 基础上，逐步增加提示扰动幅度（如 $[0, 30]$、$[0, 50]$ 像素随机外扩/内缩），并引入自动检测框（如基于预训练器官检测器的输出）作为替代提示来源，系统性评估本文方法在不同提示质量下的性能衰减曲线。若 BL 与 BL+MSL 在提示扰动下仍保持相对优势，则本文结论可更接近实际应用场景。这一验证对于判断方法在真实临床工作流中的适用性至关重要。已有研究表明，提示质量对 SAM 类模型的性能有显著影响\cite{shaharabany2023autosam,wong2024scribbleprompt}，系统性的鲁棒性验证是迈向实际应用的必要步骤。

  \item 扩展评估规模与外部验证。优先将测试集规模扩展至更大范围，并在 TotalSegmentator\cite{wasserthal2023totalsegmentator}等外部数据集上开展独立验证，以评估方法的跨数据集泛化能力。外部验证可揭示方法对不同扫描协议、设备厂商和人群分布的适应性。

  \item 扩展局部适配器的结构验证。可进一步比较不同插入位置（编码器内部各层、解码器内部）、不同分支结构、是否使用多层插入，以及 2.5D 或轻量级三维卷积适配器，以补充当前 2D 适配器无法利用跨切片上下文的不足。三维适配器可能对食管、十二指肠等细长器官的分割一致性有所帮助。已有研究表明，三维上下文信息对医学图像分割具有重要价值\cite{cicek20163dunet}，将局部适配器扩展到三维是值得探索的方向。

  \item 验证跨模态泛化性。在 MRI（如 AMOS22 MRI 子集）等其他模态上开展迁移验证，判断 Balance Loss 的训练信号重构思路是否在不同成像条件下仍然有效。跨模态验证可揭示方法对图像对比度、噪声特性和解剖可见性变化的鲁棒性。已有研究表明，CT 与 MRI 在成像机制和组织对比度上存在显著差异\cite{litjens2017survey}，跨模态验证是评估方法泛化能力的重要维度。

  \item 探索损失与结构的联合优化。当前研究采取先锁定损失再筛选结构的顺序策略。后续可探索损失设计与结构增强之间的耦合关系，例如不同局部适配结构是否需要配套不同的困难像素权重策略，或是否存在更优的联合优化路径。
\end{enumerate}

从优先顺序看，首先应围绕提示鲁棒性、跨数据集泛化性等关键边界条件进行系统验证，而非继续增加零散模块。本文构建的两步优化路径在这些维度上仍具有较大的拓展空间。
