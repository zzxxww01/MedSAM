\chapter{总结与展望}

\section{工作总结}

本文围绕 MedSAM 在医学图像分割中的两类关键问题展开研究：双重类别不平衡与空间局部高频特征先验不足。主要工作总结如下：

\begin{enumerate}
  \item \textbf{构建联合梯度平衡损失框架（A3R3）}：通过 Inter-CBL 与 Intra-CBL 联合建模类间与类内不平衡，并引入两阶段训练机制，强制解除了复杂多器官中小样本类别的学习屏蔽。通过严格的假设检验（A3R2/A3R3 单变量剥离），将原始 Balance Loss 退化的根因定位为 Inter-CBL 权重过大，最终确定 $\alpha=0.5$ 的最优配置，将基础重叠度（DSC）从 0.941 拔高至 0.959，HD95 降低 53.4\%，ASD 降低 54.2\%。
  \item \textbf{揭示了参数高效微调在复杂医学域的局限性（C2）}：通过实施秩为 4 的 LoRA 冻结主干微调\cite{hu2022lora}，在同口径腹部数据集上取得的 DSC=0.879（相比 A3R3 下降 8.3\%）的劣等性能，作为关键的消融反证，明确了"开放大模型主干进行空间流形重塑"对于医疗小样本边界切割的不可或缺性。
  \item \textbf{设计了局部-全局多尺度边缘适配器（C3）}：在不冻结主干的基础上，通过引入纯卷积并带有膨胀多尺度感受野的 Local-Global Adapter\cite{yu2016dilated, howard2017mobilenets}，以仅 0.15\% 的额外参数开销完美弥补了 ViT\cite{dosovitskiy2021vit}过度平滑高频特征的短板。该三核联合架构最终在 40 例未见病例中达到 DSC=0.9620（突破 0.96 大关），HD95=2.91 的最优指标。
\end{enumerate}

\section{研究不足}

\begin{enumerate}
  \item \textbf{跨模态与跨部位泛化性有待验证}：本文聚焦于 FLARE22\cite{ma2022flare}的腹部多器官 CT 切片，跨设备（如 MRI 或超声）跨部位数据集的泛化性验证依然依赖于后续更多的临床同源数据收集。将所提出的 Balance Loss 和 LG-Adapter 推广至其他成像模态，需要进一步的跨域适配研究。
  \item \textbf{推理效率的优化空间}：鉴于引入了额外的卷积层，使得原本就已经庞大的 MedSAM 推理和训练速度受到了一定拖累，未能实现极限部署轻量化。尽管 LG-Adapter 本身的计算开销可忽略不计（$<$1 ms/样本），但整体管线（ViT-Base 编码器 + Mask Decoder）的推理成本仍然较高。
  \item \textbf{测试集规模与统计显著性}：全部实验基于 40 例测试集进行评估，尽管这与 FLARE22 挑战赛的官方划分一致\cite{ma2022flare}，但样本量偏小导致个别 outlier 对指标影响显著（如 C3 的 HD95 轻微劣于 A3R3 可能缺乏统计显著性）。未进行交叉验证或 bootstrap 置信区间估计，也未在多个独立中心进行外部验证。
\end{enumerate}

\section{未来展望}

后续可从以下方向继续推进：

\begin{enumerate}
  \item \textbf{三维扩展}：将所设计的多尺度适配器与 3D 医学分割网络（如 nnU-Net 3D\cite{isensee2021nnunet}或 SAM 2 的视频分割框架\cite{ravi2024sam2}）结合，以获取帧间立体时序依赖信息。三维膨胀卷积可在体积数据上提供更丰富的多尺度上下文，有望进一步提升小器官（如肾上腺、十二指肠）的分割精度。
  \item \textbf{混合 PEFT 方案}：探索更为精细的混合参数高效微调策略，例如在 ViT 的浅层使用 LoRA 冻结（保留通用视觉先验），在深层开放全参微调（进行医学域特化），以期在"空间微调能力"与"低显存部署"之间找到超越当前全参微调加适配器方案的 Pareto 最优解。
  \item \textbf{交互式智能纠错}：在端侧引入大语言模型（LLM）进行交互式错误边界自动寻回与修正闭环，使得系统初步具备 AI Agent 纠错自主性。例如，通过视觉-语言模型自动检测分割结果中的异常区域并生成修正提示，实现人机协作的半自动精细化分割。
  \item \textbf{多中心外部验证}：在更大规模的多中心数据集上进行外部验证，并采用交叉验证和 bootstrap 置信区间方法提供更严格的统计评估，以增强本文方法结论的泛化可靠性。
\end{enumerate}
