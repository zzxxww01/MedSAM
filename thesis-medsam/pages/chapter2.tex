\section{MedSAM 基座模型}

\subsection{SAM 到 MedSAM 的迁移}

SAM（Segment Anything Model）\cite{kirillov2023segment}是 Meta AI 于 2023 年提出的通用分割模型，在 SA-1B 数据集（1100 万张图像、10 亿个掩码标注）上训练，建立了“Image Encoder + Prompt Encoder + Mask Decoder”的三段式架构。

MedSAM\cite{ma2024medsam}在 SAM 架构基础上进行医学领域迁移，使用超过 150 万对医学图像-掩码标注、涵盖 10 种成像模态和 30 余种肿瘤类型的大规模数据完成领域微调。微调过程冻结 Prompt Encoder，仅更新 Image Encoder 和 Mask Decoder，采用 Dice Loss 与 Cross-Entropy Loss 的组合。其预训练数据中包含腹部 CT 图像，为本文的下游任务提供了良好的特征初始化基础。在本文统一评估协议下，MedSAM 基线已达到 DSC=0.9411，表明其在腹部多器官分割上具有较强的初始能力，但在困难器官和边界指标上仍有提升空间。

\subsection{三部分结构解析}

MedSAM 的核心架构由三个模块组成\cite{kirillov2023segment, ma2024medsam}：

\begin{enumerate}
  \item Image Encoder：基于 ViT-Base\cite{dosovitskiy2021vit}，将输入图像（$1024 \times 1024 \times 3$）通过 $16 \times 16$ 的 Patch 嵌入映射到高维语义特征空间，输出 $64 \times 64 \times 256$ 的特征图（16 倍空间下采样）。ViT-Base 包含 12 个 Transformer Block，每个 Block 由多头自注意力层（Multi-Head Self-Attention）和前馈网络（FFN）组成。
  \item Prompt Encoder：将 box/point 等提示映射为位置相关编码，通过位置嵌入将框角点坐标转换为与图像特征对齐的向量表示，约束模型的关注区域。
  \item Mask Decoder：通过轻量级 Transformer 结构融合 Image Embedding 与 Prompt Embedding，经双向交叉注意力（prompt-to-image 和 image-to-prompt）和上采样层生成最终的分割掩码。
\end{enumerate}

在 MedSAM 的标准训练设定中，Prompt Encoder 通常冻结，仅更新 Image Encoder 与 Mask Decoder\cite{ma2024medsam}。图~\ref{fig:medsam_arch}展示了 MedSAM 的三段式架构及数据流向。从任务分工角度理解，Image Encoder 提供全局语义表征，Prompt Encoder 承担目标区域约束，Mask Decoder 生成最终分割掩码。本文后续改进主要围绕损失层（作用于 Mask Decoder 学习方向）和桥接特征层（作用于 Image Encoder 输出）。

\subsection{关键计算流程}

设输入图像为 \(I\)，提示为 \(P\)，可写为：
\begin{equation}
E_I = f_{enc}(I), \quad E_P = f_{prompt}(P), \quad \hat{Y}=f_{dec}(E_I,E_P)
\end{equation}
其中 \(E_I\) 为图像语义特征，\(E_P\) 为提示特征，\(\hat{Y}\) 为预测掩码。本文后续改进主要作用于 \(f_{dec}\) 的特征融合输入（第4章局部适配器）与训练目标函数（第3章 Balance Loss）。

从这一计算流程可以看出，在本文统一采用 GT box prompt 的条件下，模型性能差异主要来自图像特征的表达质量与监督信号的引导方式。本文后续改进围绕这两个方面展开。

\section{类别不平衡理论}

\subsection{有效样本数与长尾重加权}

Class-Balanced Loss\cite{cui2019classbalanced}指出，样本数量并不等价于信息量。当某类样本数量很大时，新增样本带来的信息增益递减，反映多数类信息冗余。

对于医学分割像素级任务，背景像素数量常远大于前景像素数量。若不进行再平衡，多数类将持续主导梯度方向，使模型更偏向背景预测。有效样本数理论为“削弱冗余背景影响”提供了数学依据。第 3 章中 Inter-CBL 的困难背景挖掘可以看作该思想在像素级的操作性实现：直接丢弃信息冗余度最高的简单背景像素，仅保留与前景数量对齐的困难背景子集参与梯度计算。

\subsection{困难样本挖掘}

Class-Balanced Loss 主要解决类别间的样本数量失衡，而在同一类别内部，困难像素与易分像素的学习难度差异同样需要关注。为此，困难像素挖掘（Hard Example Mining）策略应运而生。

OHEM（Online Hard Example Mining）\cite{shrivastava2016ohem}通过在每个前向传播中计算所有候选样本的损失值，按损失降序选取 top-$k$ 样本参与反向传播。Focal Loss\cite{lin2017focal}则采用连续调制因子 $-(1-p_t)^\gamma \log(p_t)$ 实现对困难像素的软聚焦。

两者共同目标是降低易分像素对梯度的主导，提升困难像素学习效率。第3章中 Intra-CBL 的设计介于两者之间——采用基于置信度误差阈值 $\tau$ 的二值分段权重（易/难二分），在保持可解释性的同时避免了 OHEM 完全丢弃易分像素信息的风险。

\subsection{双层不平衡的理论依据}

在提示式二值分割场景下，不平衡问题呈现双层结构：第一层为类别间不平衡（前景像素数量远少于背景像素），第二层为类别内不平衡（困难像素占比远低于易分像素）。本文将这种耦合现象称为双层不平衡。

传统类别不平衡方法（如 Class-Balanced Loss）主要针对多类别分类任务中的样本频次差异，通过类别级重加权缓解长尾分布问题。然而，在提示式二值分割场景下，不平衡问题呈现出更复杂的双层结构：

第一层（类别间）：前景像素数量远少于背景像素，导致梯度在类别间分配不均。若采用标准 BCE 损失，背景像素的梯度贡献占比可达 95\% 以上，前景信号被严重压制。

第二层（类别内）：在前景内部，边界、低对比和形态复杂区域的困难像素仅占 5--15\%，但这些像素恰恰决定了分割质量。若等权训练，模型倾向于优先拟合大量易分像素，导致边界过平滑。

两层失衡相互耦合：即使通过类别重加权解决了第一层问题，第二层失衡仍会导致困难像素学习不足。因此，需要分别建模两个层面的失衡，而非施加统一的连续调制（如 Focal Loss）。实验表明（详见第3章），Focal Loss 在当前任务中未能带来提升（DSC 0.9398 vs Baseline 0.9411），验证了针对两层分别设计独立机制的必要性。

其中，BCE 与 Dice 是本文的核心基础组件。两者在梯度性质上具有互补性：Dice Loss 对类别不平衡天然鲁棒，但单个困难像素的梯度贡献会被集合统计量稀释；BCE 则逐像素独立计算梯度，对困难像素的纠正更为直接。这一互补性是 MedSAM 原始训练及本文损失设计中联合使用两者的理论基础。

\subsection{BCE 与 Dice 的互补性分析}

在医学分割中，BCE 和 Dice 的联合使用已成为标准实践，但其背后的理论依据值得深入分析。

BCE 损失对每个像素独立计算交叉熵，其梯度直接反映单个像素的预测误差。对于困难像素（预测概率接近 0.5），BCE 提供较大的梯度信号，促使模型快速纠正；对于易分像素（预测概率接近 0 或 1），梯度自然衰减。这种像素级独立性使 BCE 对局部细节敏感，但也导致其易受类别不平衡影响——大量背景像素的梯度会淹没前景信号。

Dice Loss 从全局重叠度角度优化，其梯度包含归一化项 $(|Y|+|\hat{Y}|)^2$，使得前景和背景对梯度的贡献相对均衡，天然对类别不平衡鲁棒。然而，Dice 的全局归一化也意味着单个困难像素的梯度贡献被稀释——即使某个边界像素预测错误，其对总体 Dice 的影响也可能被大量正确预测的像素所掩盖。

因此，BCE + Dice 的组合实现了“局部纠正”与“全局平衡”的互补：BCE 确保困难像素获得足够的学习信号，Dice 确保前景不被背景梯度压制。本文 Balance Loss 在此基础上进一步细化：Inter-CBL 通过困难背景挖掘强化类别间平衡，Intra-CBL 通过困难像素加权强化类别内学习，两者与 Dice 共同构成三层训练信号重构机制。

\subsection{Focal Loss 失效的理论分析}

Focal Loss 在目标检测任务中表现优异，但在本文任务中未能带来改善（详见第3章实验：Baseline-Focal DSC 0.9398 vs Baseline 0.9411）。这一现象可从双层不平衡的角度理解。

Focal Loss 的连续调制因子 $(1-p_t)^\gamma$ 对所有像素施加统一形式的难度加权，不区分困难像素的来源。在本文任务中，困难像素可能来自两个不同层面：类别间的困难背景（与前景边界接近的背景像素）和类别内的困难前景（边界、低对比区域）。Focal Loss 的统一调制无法针对性地处理这两类困难像素——它既不能像 Inter-CBL 那样选择性地保留困难背景，也不能像 Intra-CBL 那样对前景内部的困难像素施加更强的权重。

此外，Focal Loss 的 $\gamma$ 参数需要全局调优，难以同时兼顾类别间和类别内的最优权重分配。而 Balance Loss 通过 $\alpha$（Inter-CBL 权重）和 $w_h$（Intra-CBL 困难像素权重）两个独立参数，可以分别控制两个层面的训练信号强度，提供了更灵活的调控空间。

\section{参数高效微调理论}

\subsection{LoRA 低秩适配}
\label{sec:lora_theory}

随着大模型参数规模急剧增长，参数高效微调（PEFT）成为迁移学习的重要范式\cite{ding2022peftsurvey}。LoRA（Low-Rank Adaptation）\cite{hu2022lora}是其中最具代表性的方法，其核心思想是对预训练权重矩阵的增量施加低秩约束：

\begin{equation}
W = W_0 + \Delta W = W_0 + BA, \quad B \in \mathbb{R}^{d \times r}, \, A \in \mathbb{R}^{r \times k}, \, r \ll \min(d,k)
\end{equation}

训练过程中冻结原始权重 $W_0$，仅更新低秩矩阵 $A$ 和 $B$，可将可训练参数量减少数个数量级。

LoRA 在 NLP 领域应用广泛，但在密集预测的医学图像分割任务上存在局限性。本文第4章的实验表明，冻结主干的 LoRA 路线效果受限（BL+LoRA-r16 DSC 0.9417 vs BL 0.9538）。其理论原因包括：首先，低秩假设在边界重建任务中的适用性有限，边界像素的特征变化往往是高维且非线性的；其次，冻结主干限制了对医学纹理的适应能力，任务特异性特征只能通过低秩旁路间接建模；第三，MedSAM 的参数量约为 94M，全参微调在单卡 V100 上即可完成，参数效率并非首要约束。

\subsection{Adapter 架构}

Adapter\cite{houlsby2019adapter}是另一类参数高效微调策略，通过在预训练模型的层间插入小型瓶颈模块来实现任务适配。与 LoRA 的区别在于：Adapter 引入了额外的网络结构（而非修改现有权重矩阵），因此可以灵活选择在模型的不同位置注入不同类型的归纳偏置。

对于本文任务而言，LoRA 与 Adapter 的关键差异在于：LoRA 以低秩增量修正已有表示，而 Adapter 允许在特定层位注入局部卷积、多尺度分支等任务相关归纳偏置。对于需要精细边界重建的医学分割任务，后者的结构可定制性往往更为重要。第4章中的 MSL-Adapter 采用双路径深度可分离卷积，专门补充局部高频响应，这种设计在 LoRA 框架下难以实现。此外，Adapter 的残差连接设计使其更适合作为在强基线上进行的局部补强模块。

\section{卷积归纳偏置与 ViT 互补性}

\subsection{ViT 的全局建模优势与局部缺陷}

Vision Transformer\cite{dosovitskiy2021vit}通过全局自注意力机制建模图像中任意两个 Patch 之间的关系，具有强大的远距离依赖捕获能力。然而，自注意力对所有空间位置一视同仁，缺乏卷积网络固有的局部平移不变性和空间层次性\cite{dai2021coatnet}。

医学图像与自然图像在高频特征分布上存在显著差异。自然图像的语义信息主要集中在中低频（物体轮廓、纹理），而医学图像的诊断关键信息往往体现在高频细节（器官边界、病灶边缘）。ViT 的 Patch 嵌入（$16\times16$）天然对高频信息进行了平滑，而医学分割中的边界往往只有 1-2 像素宽。这导致 ViT 在边界区域的特征响应相比 CNN 明显降低。

对于腹部多器官 CT 场景，大器官的分割更多依赖整体位置与形状先验，而小器官、细长器官和相邻粘连区域则更依赖局部纹理变化与细粒度边界线索。若缺少适当的局部归纳偏置补充，模型在这些高频细节区域容易产生边界过平滑或局部欠分割等现象。

\subsection{CNN 的局部归纳偏置}

卷积神经网络通过有限大小的卷积核具备局部连接和权值共享特性，对局部纹理和边缘模式具有较强归纳偏置\cite{he2016resnet}。深度可分离卷积\cite{howard2017mobilenets}进一步将标准卷积分解为逐通道的空间卷积和逐点的通道混合，在大幅降低参数量的同时保留了空间局部特征提取能力。膨胀卷积（Atrous Convolution）\cite{yu2016dilated}则通过在卷积核元素之间插入空洞来扩展感受野，能够在不增加参数量的情况下实现多尺度特征提取\cite{chen2018deeplabv3plus}。

\subsection{混合架构的理论基础}

CoAtNet\cite{dai2021coatnet}等研究表明，将卷积的局部归纳偏置与 Transformer 的全局注意力相结合，能够在各种数据规模下获得比纯 ViT 或纯 CNN 更优的性能。这一结论为在 ViT 编码器的输出特征上叠加卷积层提供了理论支撑，使模型可同时具备全局语义理解和局部边缘捕获能力。

该理论表明，局部归纳偏置并不一定需要在模型前端大规模重写主干，也可以在已具备强全局语义表示的桥接特征层上以较小代价补入，从而兼顾预训练优势与局部边界建模需求。在 MedSAM 的特征桥接位置补充局部卷积响应，可以在保留全局语义建模优势的同时，增强对边界高频特征的敏感性。

\section{注意力机制与交叉注意力融合}

\subsection{自注意力与交叉注意力}

自注意力（Self-Attention）\cite{vaswani2017attention}通过计算序列内部元素之间的相似度来动态聚合信息。给定输入序列，通过线性投影得到查询（Query）、键（Key）、值（Value）三组向量，注意力输出为各位置值向量的加权和，权重由查询与键的缩放点积经 softmax 归一化得到。

交叉注意力（Cross-Attention）则允许一个序列（Query）查询另一个序列（Key、Value）的信息。在 MedSAM 的 Mask Decoder 中，解码器特征作为 Query，编码器特征作为 Key 和 Value，实现从全局语义到局部掩码的信息传递。

\subsection{MedSAM 中 Cross-Attention 的局限性}

MedSAM 的 Mask Decoder 采用双层 Transformer Block，每层包含自注意力和交叉注意力。然而，在腹部多器官分割任务中，交叉注意力存在以下局限：

（1）特征尺度不匹配：编码器输出为 $64 \times 64 \times 256$，解码器 Token 初始化为少量可学习嵌入（如 4 个 IoU Token + 1 个 Mask Token），两者在空间分辨率和语义抽象层次上存在显著差异。交叉注意力需要将低分辨率的抽象 Token 与高分辨率的密集特征对齐，这一过程在小器官和边界区域容易产生信息损失。

（2）全局平均倾向：交叉注意力的 softmax 归一化机制倾向于在所有空间位置上分散注意力权重。对于大器官（如肝脏），这种全局聚合是合理的；但对于小器官（如肾上腺）或细长器官（如胰腺），关键信息集中在少数像素，全局平均会稀释这些局部线索。

（3）缺乏局部归纳偏置：交叉注意力本质上是全局操作，缺乏卷积的局部连续性假设。在医学图像中，器官边界通常表现为连续的高频特征，而交叉注意力无法显式建模这种空间连续性。

这些局限性导致 MedSAM 在处理小器官、细长器官和边界粘连区域时，容易出现边界模糊、局部欠分割等问题。

\subsection{跨样本 Cross-Attention 的适用性分析}

在少样本分割（Few-Shot Segmentation）领域，交叉注意力被广泛用于建立支持样本（support）与查询样本（query）之间的特征对齐。PANet\cite{wang2019panet}提出的 support-query 原型对齐是典型应用：从支持样本中提取类别原型，通过注意力机制将其与查询图像特征对齐，从而将已有的分割知识迁移到新样本。

然而，这一策略在与已具备稳定医学迁移初始化的预训练模型结合时需要审慎评估。对于 MedSAM 而言，其 Image Encoder 已在 150 万对医学图像-掩码上建立了较为完善的器官语义表征。此时额外注入的跨样本参考特征可能与原有特征分布不一致，进而破坏预训练表征的稳定性。具体而言：

（1）特征分布冲突：预训练编码器的特征空间已针对医学图像的统计特性进行了优化，而跨样本交叉注意力引入的参考特征可能来自不同扫描协议、不同对比度的图像，两者在特征空间中的分布可能存在偏移。强行对齐可能导致特征空间的扰动，削弱预训练知识的稳定性。

（2）推理复杂度增加：跨样本交叉注意力需要在推理阶段预先编码参考样本，并维护参考特征库。这不仅增加了计算开销，还引入了参考样本选择的额外超参数（如选择哪些样本、如何聚合多个参考特征），在实际部署中带来额外负担。

（3）问题定位偏差：若当前误差主要来自局部边界表征不足（如小器官边界模糊、细长器官断裂）而非全局语义不充分，继续向桥接层注入跨样本参考信息未必比直接补足局部归纳偏置更具针对性。全局语义对齐无法解决局部高频特征缺失的问题。

因此，在已具备强预训练基础的 MedSAM 上，直接补充局部卷积归纳偏置可能是更简洁、更有效的改进方向。这一分析性判断将在第4章通过实验加以验证。

\section{评价指标与实验口径}

本文采用 DSC（Dice Similarity Coefficient）、HD95（95\% Hausdorff Distance）和 ASD（Average Surface Distance）三项指标\cite{taha2015metrics}评价模型分割性能，以病例为统计单位。

\subsection{三项指标的互补性}

DSC 衡量预测掩码与真实掩码的区域重叠度，对整体分割质量敏感，但对边界细节不敏感。对于大器官（如肝脏），即使边界存在数像素偏移，DSC 仍可能保持较高值；而对于小器官（如肾上腺），少量像素误差即可导致 DSC 显著下降。

HD95 衡量预测边界与真实边界之间的最大距离（排除 5\% 离群点），对边界离群误差敏感。它能够捕捉局部边界的严重偏移（如细长器官的断裂、粘连区域的过分割），但对整体分割完整性不敏感。

ASD 衡量预测边界与真实边界之间的平均距离，对边界整体质量敏感。它能够反映边界的平均偏移程度，但对局部离群误差不如 HD95 敏感。

三项指标的互补性体现在：DSC 评估整体重叠、HD95 评估最坏情况、ASD 评估平均质量。联合使用可以全面评估模型在不同器官尺度、不同边界复杂度下的性能。

\subsection{病例级统计的必要性}

医学图像分割的评估应以病例（患者）为统计单位，而非以切片为单位。原因在于：

（1）临床相关性：临床诊断和治疗决策基于完整的三维病例，而非单个二维切片。以病例为单位的评估更符合实际应用场景。

（2）避免伪独立性：同一病例的不同切片在解剖结构、扫描参数、图像质量上高度相关，若以切片为单位统计，会高估样本独立性，导致统计检验的 p 值失真。

（3）器官尺度差异：不同器官在三维空间中占据的切片数差异巨大（如肝脏可能跨越 100+ 切片，而肾上腺仅 5-10 切片）。以切片为单位统计会使大器官的权重过高，掩盖小器官的性能差异。

因此，本文在第5章的实验中，所有指标均以病例为单位计算均值和标准差，确保统计结论的临床相关性和统计有效性。详细的评估协议设定见第5章。

\section{本章小结}

本章系统梳理了本文方法所依赖的理论与技术基础，并在每个主题下增加了针对腹部多器官分割任务的理论分析：

（1）MedSAM 基座模型：介绍了 MedSAM 的架构、预训练数据规模（150 万对图像-掩码、10 种模态、30+ 肿瘤类型）和基线性能，为后续改进提供起点。

（2）类别不平衡理论：阐述了双层不平衡（类别间失衡与类别内失衡）的理论依据，解释了为什么传统类别不平衡方法不适用于提示式二值分割，以及为什么需要分别建模两种失衡。

（3）损失函数基础：分析了 BCE 与 Dice 的互补性（逐像素监督 vs 全局重叠监督）、Focal Loss 在医学分割中的失效原因（难度定义不适配、梯度抑制过强），为第3章的平衡损失设计提供理论支撑。

（5）卷积与 ViT 互补性：分析了 ViT 在医学图像上的特性（高频特征平滑、边界响应降低）和局部适配器的理论基础（桥接位置插入卷积的合理性），为第4章的混合架构设计提供理论支撑。

（7）评价指标：分析了 DSC、HD95、ASD 三项指标的互补性（整体重叠 vs 最坏情况 vs 平均质量）和病例级统计的必要性（临床相关性、避免伪独立性、器官尺度差异）。
