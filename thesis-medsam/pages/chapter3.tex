\chapter{联合平衡损失框架的设计与配置筛选}

本章旨在确定后续结构增强所需的损失函数配置。本章按论证逻辑组织内容：首先定义训练信号分配问题，随后给出联合平衡损失（Balance Loss, BL）的方法设计，再通过统一比较筛选最终配置，最后以补充分析验证该配置的合理性。本章重点在于通过系统消融实验论证 BL 作为损失主干的合理性，为后续章节的结构增强提供稳定基础。

\section{问题定义与方法设计}

在 MedSAM 的提示式分割框架下，模型输出本质上是前景/背景二值掩码。如第2章所述，这一场景下的不平衡问题呈现双层结构：类别间（前景/背景数量失衡）与类别内（困难/易分像素失衡）。本节通过定量分析验证这一问题的严重性。

为定量说明这一问题的严重性，本文在 FLARE22\cite{ma2022flare} 和 AMOS22\cite{ji2022amos} 数据集上统计了像素分布特征。在 5410 张训练切片中，前景像素占比平均为 12.3\%（标准差 6.8\%），不同器官类别间差异显著：肝脏等大器官前景占比可达 20\%--25\%，而胰腺、肾上腺等小器官仅占 3\%--8\%。进一步分析困难像素分布（以置信度误差 $e_i = |p_i - y_i| > 0.9$ 为标准），发现困难像素在前景中的占比约为 8\%--15\%，且主要集中在器官边界（占困难像素的 60\%--70\%）和低对比区域（占 20\%--30\%）。在等权训练下，困难边界像素仅占总梯度贡献的不足 1\%，其学习信号易被大量简单背景像素所压制。

这两层失衡相互耦合，导致传统的单一层面策略难以同时解决两个层面的问题。Focal Loss\cite{lin2017focal} 通过连续调制因子 $(1-p_t)^\gamma$ 对所有像素施加统一的难度加权，但在当前任务中其表现反而略低于基线（见第 3.3 节表~\ref{tab:unified_loss}）。这表明其统一的连续调制策略无法针对性地处理双层失衡的不同来源，验证了分层建模的必要性。

基于这一问题建模，本文设计联合平衡损失框架 Balance Loss，将类别间平衡（Inter-Class Balanced Loss, Inter-CBL）与类别内困难像素加权（Intra-Class Balanced Loss, Intra-CBL）联合建模，并通过两阶段训练缓解训练初期的噪声干扰。从梯度流角度看，Inter-CBL 通过困难背景挖掘削弱冗余背景对梯度的主导作用，使前景与背景的梯度贡献趋于平衡；Intra-CBL 则通过困难像素加权放大边界区域的梯度信号，使模型在已有粗分割能力基础上进一步关注细粒度边界。两者分离建模而非统一调制的设计，使得可以通过独立的权重参数（$\alpha$ 和 $\beta$）控制两个层面的交互强度，避免单一调制因子在不同失衡层面间的冲突。

为便于后续叙述，本文对 Balance Loss 相关符号做统一约定：$p_i$ 表示像素 $i$ 的模型预测前景概率，$y_i \in \{0,1\}$ 为对应的真实标签，$\ell_i = -[y_i \log p_i + (1-y_i)\log(1-p_i)]$ 为像素级二值交叉熵损失。前景像素集合记为 $F$，全部背景像素集合记为 $B$，类别间平衡损失（Inter-Class Balanced Loss, Inter-CBL）从 $B$ 中挖掘得到的困难背景子集记为 $H_B$。类别内困难像素加权损失（Intra-Class Balanced Loss, Intra-CBL）中，像素 $i$ 的置信度误差 $e_i = |p_i - y_i|$，基于阈值 $\tau$ 将像素划分为易分像素集合 $E = \{i : e_i \leq \tau\}$ 与困难像素集合 $H = \{i : e_i > \tau\}$。

需要说明的是，本文所提 Balance Loss 与 Cui 等人\cite{cui2019classbalanced}的 Class-Balanced Loss 在名称上存在相似性，但两者的设计目标与技术路线不同。Class-Balanced Loss 基于有效样本数理论对多类别分类任务中的长尾类进行损失重加权，属于单一层面的类别间重平衡策略；本文 Balance Loss 则针对像素级二值分割中类别间与类别内两个层面同时失衡的问题，将 Inter-CBL 与 Intra-CBL 联合建模，并辅以两阶段训练策略。Balance Loss 与已有不平衡/边界损失方法的核心区别在于：Focal Loss 对所有像素施加统一连续调制，不区分两层失衡；OHEM 按损失值选取困难像素，不区分困难像素来源（前景或背景）；Boundary Loss 直接优化边界距离，属于目标函数层面改进。Balance Loss 则从训练信号分配角度出发，将两个层面分解为独立组件并通过 $\alpha$ 权重控制交互强度，实现结构化的梯度重构。

\subsection{Inter-CBL：类别间平衡损失}

多数背景像素属于易分类像素，若全部参与反向传播，会在梯度层面压制前景信号。为此，本文仅选择与前景数量对齐的困难背景像素参与计算，避免背景梯度主导。该策略受到有效样本数理论\cite{cui2019classbalanced}和在线困难样本挖掘\cite{shrivastava2016ohem}的启发。

设前景像素集合为 $F$，背景中挖掘得到的困难背景像素集合为 $H_B$，像素级 BCE 损失为 $\ell_i = -[y_i \log p_i + (1-y_i)\log(1-p_i)]$，则：
\begin{equation}
L_{inter}=\frac{1}{2}\left(\frac{1}{|F|}\sum_{i\in F}\ell_i+\frac{1}{|H_B|}\sum_{j\in H_B}\ell_j\right)
\end{equation}

具体实现中，对所有背景像素按预测前景概率降序排列，选取前 $|F| \times \text{neg\_ratio}$ 个像素作为困难背景集合 $H_B$，其中 $\text{neg\_ratio}=3.0$。这一挖掘策略的有效性在于：预测前景概率高的背景像素往往位于前景边界附近或与前景具有相似纹理特征的区域，这些像素对模型而言具有真正的判别难度，而非训练初期的随机噪声。相比按损失值排序（易受标签噪声影响）或按距离前景边界的距离排序（需要额外的边界提取步骤），按预测概率排序既简单高效又能准确捕捉模型当前的困惑区域。

$\text{neg\_ratio}=3.0$ 的选择在覆盖边界附近关键区域与避免背景重新主导梯度之间取得平衡。参考目标检测中正负样本配比的经验（如 OHEM\cite{shrivastava2016ohem} 中的 1:3 设定），该比例确保困难背景样本数量约为前景的 3 倍，既能充分覆盖前景边界附近的混淆区域，又将参与计算的背景像素压缩至全部背景的较小比例，从而有效削弱冗余背景对梯度的干扰。为验证这一选择，本文补充了 $\text{neg\_ratio}$ 的敏感性测试，结果如表~\ref{tab:neg_ratio_ablation}所示。

\subsection{Intra-CBL：类别内困难像素加权损失}

仅解决类别间不平衡并不足以保证模型关注边界与低对比区域。对于同一类别内部，易分像素多而困难像素少，若等权训练，模型更可能优先拟合简单区域。为此，本文引入基于置信度误差阈值的困难像素划分机制，对困难像素赋予更高权重。

将像素集合按置信度误差划分为易分像素 $E$ 与困难像素 $H$。设像素 $i$ 的置信度误差为 $e_i = |p_i-y_i|$，其中 $p_i$ 为预测概率，$y_i$ 为真实标签，则：
\begin{equation}
H = \{i : e_i > \tau\}, \quad E = \{i : e_i \leq \tau\}
\end{equation}

对应加权 BCE 损失为：
\begin{equation}
L_{intra}=w_e\cdot \frac{1}{|E|}\sum_{i\in E}\ell_i + w_h\cdot \frac{1}{|H|}\sum_{j\in H}\ell_j
\end{equation}

其中 $w_e = 1.0$，$w_h = 2.0$。该策略与 Focal Loss\cite{lin2017focal}关注困难像素的目标一致，但采用分段权重而非连续调制，具有更好的可解释性和调参便利性。

为理解困难像素的分布特征，本文在训练集上统计了不同 $\tau$ 阈值下困难像素的空间分布。当 $\tau{=}0.9$ 时，困难像素主要集中在三类区域：器官边界（占困难像素的 60\%--70\%）、低对比区域（占 20\%--30\%，如肝脏与周围软组织的交界）、小器官内部（占 5\%--10\%，如胰腺、肾上腺）。不同器官类别的困难像素占比存在显著差异：肝脏等大器官的困难像素占比约为 8\%--12\%，主要分布在边界；胰腺、肾上腺等小器官的困难像素占比可达 15\%--20\%，既包括边界也包括内部低对比区域。这一分布特征说明，$\tau{=}0.9$ 能够有效捕捉真正需要模型关注的困难区域，而非将大量中等难度像素误判为困难像素。

$w_h{=}2.0$ 的选择基于以下考量：在 $\tau{=}0.9$ 时困难像素约占全部前景像素的 8\%--15\%，适度放大其权重可改善梯度贡献而不至于引入过大方差。与 Focal Loss 的连续调制因子 $(1-p_t)^\gamma$（典型取 $\gamma=2$）相比，$w_h{=}2.0$ 的离散权重在困难像素比例较低时提供了相近数量级的有效加权，同时避免了连续调制在极端概率区间的数值不稳定。为验证 $w_h$ 选择的合理性，本文补充了 $w_h$ 的敏感性实验（表~\ref{tab:wh_ablation}），结果表明 $w_h$ 在 1.5--3.0 范围内性能差异较小（DSC 波动 $<$ 0.002），进一步支持将其固定为 2.0 的决策。

此外，Intra-CBL 采用离散分段权重而非连续调制的设计，使其在梯度分配机制上与 Focal Loss 存在本质区别。Focal Loss 的连续调制因子 $(1-p_t)^\gamma$ 对所有像素施加平滑的难度加权，但在 $p_t$ 接近 0 或 1 时会产生极端的梯度缩放（如 $p_t{=}0.99$ 时调制因子为 $0.01^\gamma{=}0.0001$），容易导致数值不稳定。Intra-CBL 的离散权重则将像素明确划分为易/难两类，避免了极端概率区间的数值问题，同时保持了对困难像素的有效加权。实验结果（见第 3.3 节表~\ref{tab:unified_loss}）表明，Baseline-Focal 的表现反而略低于 Baseline，进一步验证了离散权重在当前任务中的优势。

\subsection{完整损失与两阶段训练策略}

最终损失定义为：
\begin{equation}
L_{balance}=\alpha L_{inter}+\beta L_{intra}+\gamma L_{dice}
\end{equation}
其中 $L_{dice}$ 为标准 Dice 损失\cite{milletari2016vnet}。本文实验中固定 $\beta=1.0$、$\gamma=1.0$，将 $\alpha$ 作为 Inter-CBL 强度的主要调控变量。

直接在训练起始阶段启用完整 Balance Loss 会导致性能退化。从优化景观角度看，训练初期模型预测近似随机（前景概率接近 0.5），此时按预测概率排序挖掘的困难背景实际上是伪困难像素——它们的高预测概率并非源于真实的判别难度，而是源于模型尚未建立有效的前景/背景区分能力。这些伪困难像素的梯度方向具有较大随机性，若在此阶段引入 Inter-CBL，会放大无效梯度并干扰优化方向。

为此，本文采用两阶段训练策略：
\begin{itemize}
  \item Stage 1（Epoch 0 至 $T_1$）：仅启用 $L_{intra}+L_{dice}$，先建立基础判别能力。在此阶段，模型学习粗分割能力，使预测从随机分布收敛到有意义的前景/背景分布，为后续困难背景挖掘奠定基础。
  \item Stage 2（Epoch $T_1$ 至训练结束）：引入完整的 $\alpha L_{inter}+\beta L_{intra}+\gamma L_{dice}$。在已有判别能力基础上，Inter-CBL 能够更可靠地识别真正的困难背景（如前景边界附近的混淆区域），从而精细调整类别间梯度平衡。
\end{itemize}

这一两阶段策略的有效性可从实验结果得到验证：BL-T0 配置（$T_1{=}0$，即从 Epoch 0 起启用完整 Balance Loss）的 DSC 仅为 0.9470，明显低于 BL（$T_1{=}50$，DSC 0.9538），说明训练初期引入 Inter-CBL 确实会因伪困难像素干扰而导致性能退化。

后续主线实验最终采用的超参数配置为：$\alpha = 0.5$，$\beta = 1.0$，$\gamma = 1.0$，$T_1 = 50$，$\tau = 0.9$，$w_h = 2.0$，$\text{neg\_ratio} = 3.0$。这一配置的选择过程将在后续实验中给出。

关于两阶段切换方式，本文采用硬切换（在 $T_1$ 时刻直接引入完整 Inter-CBL）而非渐进式过渡（如线性递增 $\alpha$ 权重）。为验证这一选择，本文补充了渐进式过渡实验 BL-prog（$\alpha$ 在前 $T_1$ 个 epoch 内从 0 线性递增至 0.5，其余参数与 BL 一致），结果如表~\ref{tab:unified_loss}补充验证组所示。BL-prog 的 DSC 为 0.9531，略低于硬切换 BL 的 0.9538。这说明硬切换在当前配置下已足够有效，其原因可能在于：硬切换能使模型在 Stage 2 开始时立即接收完整的 Inter-CBL 梯度信号，而渐进递增在早期阶段的 Inter-CBL 权重过小，无法充分发挥类别间重平衡作用。此外，硬切换更便于控制实验变量，使 $T_1$ 消融的解释更清晰。从训练曲线（图~\ref{fig:training_curves}）亦可观察到，硬切换虽引起短暂波动但能迅速恢复稳定下降，说明当前训练规模下硬切换并未造成不可逆的优化方向偏离。

除硬切换与线性递增外，其他可能的两阶段过渡策略还包括余弦退火引入和损失值触发引入。本文未对这些变体进行系统消融，原因在于：BL-prog 的渐进过渡实验已表明硬切换在当前配置下不弱于渐进策略；$T_1$ 消融已覆盖了不同切换时机对性能的影响，其波动幅度远小于 $\alpha$ 消融，说明具体的过渡形式并非首要敏感因素。

\section{候选损失配置与统一评估口径}

本章所有实验均服务于同一个目标：筛选后续章节统一采用的损失主干。为保证不同候选配置之间的比较具有可解释性，本文对全部方案采用统一的数据预处理、训练轮数、优化器设置和评估口径，仅改变损失相关组件及其超参数。

本章实验的数据来源、训练配置、评估口径和数据增强策略与第5章完全一致（详见第5章第1节），此处仅列出与损失消融直接相关的设置要点：

\begin{itemize}
  \item 训练数据：联合 FLARE22\cite{ma2022flare}（40 例，3621 张前景切片）与 AMOS22\cite{ji2022amos} CT 子集（20 例，1789 张前景切片），合计 5410 张前景切片；
  \item 评估对象：15 个测试病例（10 个 FLARE22 + 5 个 AMOS22 CT，共 1295 张前景切片，与训练集无重叠）；
  \item 推理提示：统一采用 GT box prompt；
  \item 比较原则：各候选配置在统一实验条件下进行评估，以确定其作为后续主干的适用性。
\end{itemize}

为便于引用，本文将 MedSAM 原始基线记为 Baseline，Balance Loss 最优配置（$\alpha{=}0.5$, $T_1{=}50$, $\tau{=}0.9$）记为 BL，最终方案（BL + MSL-Adapter）记为 BL+MSL。损失消融中的各变体以对应超参数后缀标识，如 BL-$\alpha$0.3 表示 $\alpha{=}0.3$ 的配置，BL-T30 表示 $T_1{=}30$ 的配置；仅启用单一组件的配置以组件名标识，如 Inter-only 和 Intra-$\tau$0.9。

从表~\ref{tab:unified_loss}基线对照组显示，单独启用 Inter-CBL 的 Inter-only 与 Baseline 性能相近，表明仅从类别间重平衡角度削弱冗余背景的影响，不足以显著改善当前任务表现。Baseline-Focal 采用 Dice+Focal Loss 组合，其结果略低于 Baseline（DSC 0.9398 vs 0.9411），表明 Focal Loss 的连续调制策略在当前双层不平衡场景下未能带来改善。

基线对照组还纳入了三种已有的代表性损失策略。其中，Baseline-BdLoss（Boundary Loss）和 Baseline-ABL（Active Boundary Loss）在边界指标上有所改善，但 DSC 提升有限。

Baseline-OHEM 在基线对照组中表现最优（DSC 0.9456），但仍与 BL（DSC 0.9538）存在明显差距。

OHEM 与 Balance Loss 的关键区别在于：OHEM 按损失值不加区分地选取困难像素。Balance Loss 则将类别间重平衡与类内困难加权分离为两个独立组件，并通过两阶段策略控制其启用时机。

Inter-only（DSC 0.9420）的增益明显小于 Intra-$\tau$0.9（DSC 0.9468），这一交叉对比表明 Intra-CBL 是 Balance Loss 的首要增益来源，而 Inter-CBL 更多扮演辅助补充角色。

为深入理解 Baseline-Focal 未能改善的机制，本文分析了其在典型失败案例上的表现。在胰腺等小器官的边界区域，Focal Loss 的连续调制因子 $(1-p_t)^\gamma$ 在 $p_t$ 接近 0.5 时产生较大梯度权重（约为原始权重的 4 倍），但这些高权重像素中混杂了大量伪困难像素——它们的预测不确定性并非源于真实的判别难度，而是源于训练初期的随机性或标注噪声。相比之下，Balance Loss 的 Intra-CBL 通过阈值 $\tau{=}0.9$ 明确划分困难/易分像素，仅对置信度误差大于 0.9 的像素施加 2 倍权重，有效过滤了中等不确定性区间的噪声样本。这一对比表明，Balance Loss 的有效性源于 Inter-CBL 与 Intra-CBL 在两个不同层面的协同设计，而非单纯引入困难样本加权机制。

Intra-CBL $\tau$ 消融组展示了困难像素阈值 $\tau$ 的影响。$\tau=0.5$ 时阈值过低，大量像素被划入困难集合导致加权失去区分度，DSC（0.9406）甚至略低于 Baseline；随着 $\tau$ 提升到 0.7 以上，仅有真正的困难像素获得更高权重，性能开始明显超过基线；当 $\tau$ 处于 0.8--0.9 区间时，指标差异已较小，表明 Intra-CBL 在高阈值区间具有较好的稳健性。补充验证组中的 BL-$\tau$0.8（DSC 0.9534）与 BL（$\tau=0.9$, DSC 0.9538）差异仅为 0.0004，进一步确认了 $\tau$ 在高阈值区间的稳定性。Intra 系列在高阈值区间（$\tau \geq 0.7$）相比基线的稳定提升表明，当困难像素划分阈值设置合理时，类内加权机制可有效改善性能。

Inter-CBL $\alpha$ 消融组在固定 $T_1{=}50$、$\tau{=}0.9$ 的条件下，仅改变 Inter-CBL 的权重 $\alpha$。结果呈现出清晰的倒 U 型趋势：$\alpha=0.3$ 时 Inter-CBL 作用偏弱，收益有限但整体稳定；$\alpha=0.5$（BL）达到最优均衡点；$\alpha=0.7$ 时已出现明显退化，DSC 降至 0.9462；$\alpha=1.0$ 则进一步退化至 DSC 0.9294。

从梯度冲突角度理解这一倒 U 型趋势：当 $\alpha$ 过小时，Inter-CBL 的梯度贡献不足以有效平衡类别间失衡；当 $\alpha$ 过大时，Inter-CBL 的强梯度会压制 Intra-CBL 对困难像素的加权效果。具体而言，在 $\alpha{=}1.0$ 时，Inter-CBL 与 Intra-CBL 的权重相等（$\alpha{=}\beta{=}1.0$），但由于 Inter-CBL 作用于 $F \cup H_B$（前景 + 困难背景），而 Intra-CBL 作用于全部像素，Inter-CBL 的单位像素梯度强度实际上更高。这导致模型在优化过程中过度关注类别间平衡，而忽略了类别内部困难像素的细粒度学习需求。典型失败案例分析表明：在胰腺、肾上腺等小器官上，BL-$\alpha$1.0 的边界预测明显粗糙，HD95 从 BL 的 3.24 mm 退化至 5.62 mm，验证了过强的 Inter-CBL 确实削弱了边界学习能力。

两阶段切换 $T_1$ 消融组在固定 $\alpha{=}0.5$、$\tau{=}0.9$ 的条件下，仅改变 Stage 2 的启用时机。$T_1=0$（即从训练起始即启用完整 Balance Loss，不进行两阶段划分）的 DSC 仅为 0.9470，虽高于 Baseline 但明显低于其他 $T_1$ 设置，表明在模型预测近似随机的训练初期直接引入 Inter-CBL 会导致困难背景挖掘产生大量噪声性伪困难像素，干扰优化方向。$T_1=30$ 时模型基础判别能力仍不够充分，性能进一步提升但尚未达到最优；$T_1=50$（BL）取得最优结果；$T_1=70$（BL-T70）和 $T_1=100$ 时，虽然训练初期更稳定，但 Inter-CBL 作用时间缩短，整体收益反而下降。$T_1$ 消融呈现倒 U 型趋势，且 $T_1=0$ 作为极端设置进一步验证了两阶段训练策略的必要性。从波动幅度看，$T_1$ 在 30--100 范围内的 DSC 差异不超过 0.0019，而 $\alpha$ 在 0.5--1.0 范围内的 DSC 差异高达 0.0244，表明 $\alpha$ 是影响最终性能的主要因素，$T_1$ 的影响相对次要，但 $T_1=0$ 的显著退化（DSC 降至 0.9470）表明两阶段策略本身不可省略。

BL-cv（$\alpha=1.0$, $T_1=100$）作为高 $\alpha$ 与延后切换的交叉验证配置，其 DSC 仅为 0.9308，仍与 BL-$\alpha$1.0（DSC 0.9294）接近。结合 $\alpha$ 消融组中 $\alpha{=}1.0$ 的显著退化以及 $T_1$ 消融组中 $T_1{=}100$ 的温和退化（DSC 仍为 0.9519），可以推断 BL-cv 的退化主要由过大的 $\alpha$ 所驱动。这一交叉验证进一步确认：即使延后 Inter-CBL 的引入时机，只要 $\alpha$ 仍过大，退化就无法避免。

图~\ref{fig:sensitivity}以折线图形式展示了 $\alpha$ 和 $T_1$ 两个关键超参数对 DSC 和 HD95 的影响趋势，直观地呈现了倒 U 型变化规律。综合消融实验结果可以得出：Balance Loss 的有效性并非源于单一参数的偶然命中，而是在 $\alpha$ 和 $T_1$ 两个维度上呈现出可复现的趋势规律——$\alpha$ 控制训练信号强度，$T_1$ 控制引入时机，二者共同决定了损失分量的交互质量，且 $\alpha$ 是首要因素。

\section{本章小结}

本章针对损失函数配置筛选问题，对 Balance Loss 的设计与配置选择过程进行了系统论证。通过基线对照确认各组件的独立贡献，通过 $\tau$、$\alpha$、$T_1$ 三组单变量消融揭示超参数的影响趋势，并以交叉验证配置确认 $\alpha$ 为首要敏感因素。实验结果表明，Intra-CBL 是首要增益来源，而 Inter-CBL 需在合适权重和两阶段训练策略配合下才能发挥补充作用。本文最终确定 BL（$\alpha{=}0.5$, $T_1{=}50$, $\tau{=}0.9$）为后续章节统一采用的损失主干。
