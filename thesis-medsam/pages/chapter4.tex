\chapter{微调路线比较与局部适配方案选择}

第3章已确定 BL 为统一损失主干。本章在此基础上，比较不同微调与结构增强策略的适用性，回答最终保留局部适配路线的原因，完成研究路线的收敛。

\section{研究动机}

第3章表明，Balance Loss 显著改善了训练信号分配，使模型在困难器官和边界相关指标上获得稳定增益。但损失优化并不能完全解决 ViT 编码器在局部高频表征上的先天不足。对于胰腺、食管、十二指肠和肾上腺等边界模糊、形态细长或体积较小的器官而言，仅依赖全局语义建模仍可能出现边界过平滑和局部细节欠刻画的问题。

因此，在固定 BL 后，本文继续比较多条可能的增强路线。Cross-Attention 与 LoRA 主要作为负向对照和路线排除依据，局部适配器则是在统一比较后被保留的方案。通过这一路线筛选过程，最终模型并非简单叠加模块，而是多条路线筛选后留下的最小有效组合。

\section{微调与适配路线统一比较}

基于上述误差分析，“局部边界建模”可通过多种技术路径实现：引入跨样本参考信息以增强局部判别力（Cross-Attention 路线）、通过参数高效微调在冻结主干的前提下进行轻量级适配（LoRA 路线）、或直接插入局部卷积模块显式补充高频纹理响应（局部适配器路线）。本节将这三条路线纳入统一比较框架，以实验数据回答：哪种技术路径最适合当前任务的剩余误差形态。

\subsection{候选路线与实验设置}

本章在统一的 BL 损失主干下，比较以下几类候选路线：
\begin{itemize}
  \item \textbf{BL}：仅采用最优损失主干，不进行额外结构增强；
  \item \textbf{BL+CA}：Cross-Attention 融合路线，用于考察跨样本特征融合是否有助于进一步提升表现；
  \item \textbf{BL+LoRA-r4/r8/r16}：冻结 Image Encoder，仅通过不同秩的 LoRA 旁路进行参数高效微调；
  \item \textbf{BL+MSL}：在 Image Encoder 与 Mask Decoder 全参更新的基础上，引入局部适配器进行结构补强（Prompt Encoder 沿用 MedSAM 默认冻结设定）。
\end{itemize}

为保证路线比较的公平性，本文在固定 BL 损失主干的基础上，对不同结构增强方案采用相同的数据、训练轮数和评估协议，仅改变微调方式或附加结构。通过这种设置，性能差异可以更直接地反映不同结构路线与当前任务需求之间的匹配程度。

对于 Cross-Attention 路线（BL+CA），本文在 Image Encoder 输出与 Mask Decoder 输入之间的桥接位置插入一个标准 Cross-Attention 模块（单头，隐藏维度 256，额外参数约 263K）。该模块以当前样本的编码器特征为 Query，以同一训练批次中随机选取的另一个样本（针对同一器官类别）的编码器特征为 Key 和 Value，通过交叉注意力机制引入跨样本参考信息。该设计旨在考察少样本分割中常用的 support-query 对齐策略\cite{wang2019panet}以及通用分割中的跨样本参考机制\cite{butoi2023universeg}是否能为已有强基线带来额外增益。

对于 LoRA 路线，本文将其作为具有代表性的参数高效微调对照纳入实验。具体而言，LoRA 插入至 Image Encoder 的注意力投影层，冻结原始主干参数，仅更新低秩旁路矩阵以及下游解码相关参数；损失函数、优化器和训练轮数均与 BL 保持一致，仅改变 LoRA 秩 $r$。LoRA\cite{hu2022lora}最初在自然语言处理任务上取得成功，后续被广泛应用于视觉模型的高效微调\cite{ding2022peftsurvey}。这样的设置有助于回答一个具体问题：在当前腹部多器官分割任务中，是否可以仅依赖参数高效微调，而不开放主干特征继续适配。

对于局部适配器路线（BL+MSL），本文在 Image Encoder 与 Mask Decoder 之间的桥接位置插入一个轻量级卷积模块（Multi-Scale Local Adapter，简称 MSL-Adapter），用于显式补充局部高频纹理与边界响应。该模块采用双路径设计（膨胀率 $d=1$ 和 $d=2$），通过深度可分离卷积在不同感受野下捕获局部模式，额外参数约 136K。与 Cross-Attention 和 LoRA 不同，MSL-Adapter 不依赖跨样本参考或冻结主干假设，而是直接在特征传递路径上进行局部增强。该路线的详细设计将在第 4.5 节展开。

从表~\ref{tab:route_selection}可以看出，Cross-Attention 路线和冻结主干的 LoRA 路线均未优于 BL。其中，BL+CA 相比 BL 出现回落，表明在当前实现方式下，直接引入跨样本参考特征并未转化为稳定增益；LoRA 路线虽然随秩增大性能有所改善（r4: 0.9328 → r8: 0.9386 → r16: 0.9417），但即便 r16 已略超 Baseline（0.9411），与 BL（0.9538）仍有较大差距，表明仅依赖冻结主干与低秩旁路，难以完成当前多器官分割任务所需的充分特征适配。

从路线比较的整体结果可得出更明确的判断：在当前任务中，真正制约性能继续提升的因素并非缺少更强的全局语义融合机制，而是现有强基线在局部结构表征上仍存在剩余误差。BL+CA 的回落表明额外引入跨样本参考特征并未自然转化为更好的局部分割；LoRA 的受限表明仅依赖参数高效微调不足以完成复杂器官边界所需的充分特征重塑；而 BL+MSL 的稳定提升则表明，当训练信号已由 BL 优化后，局部结构补强才是更匹配当前误差形态的改进方向。

因此，第4章的结论并非仅为局部适配器最优的简单判定，而是完成了研究链条的收束：在 BL 解决训练信号分配问题之后，后续最值得投入的方向是局部边界建模，而非继续扩大外部参考信息或追求冻结主干条件下的参数效率。这一路线选择使最终方案的组成具有更强的可解释性——BL+MSL 并非随意叠加在 BL 之上的附加模块，而是围绕剩余误差类型自然延伸的改进措施。

\section{负向路线的筛选意义}

BL+CA 和 LoRA 路线虽未被最终保留，但其负向结果为路线选择提供了重要的排除依据。

BL+CA 的回落表明，在 MedSAM 已具备稳定预训练表示的条件下，直接在桥接位置注入跨样本参考特征可能打破原有特征分布一致性。更深层的原因在于：（1）训练与推理阶段的参考样本选取方式不一致（训练时随机采样 vs 推理时固定参考），导致模型难以学习到稳定的跨样本对齐模式；（2）跨样本特征融合隐含地假设不同样本间存在可迁移的共性模式，但在器官形态、对比度和病理状态差异较大的医学图像中，这一假设可能不成立；（3）推理阶段还需额外编码参考样本，增加部署负担。

LoRA 路线的结果则呈现出“增大秩虽有收益，但整体仍受限制”的一致趋势：$r=16$ 时 DSC（0.9417）已略超 Baseline 基线（0.9411），但与 BL（0.9538）仍有差距。这表明问题并不只是秩不够大，而是冻结主干这一前提本身限制了对医学图像域特征的充分重塑。本文关注的关键难点是复杂器官边界与细粒度轮廓的持续重建，此类误差要求主干特征在空间表征上进行更充分的再适配。

\subsection{适配器贡献的精确评估}

BL+MSL 的性能增益同时受益于两个因素：主干全参更新对特征空间的充分适配，以及 MSL-Adapter 对局部边界表征的定向补强。由于 LoRA 路线冻结了主干参数，其与 BL+MSL 的性能差距不能完全归因于适配器结构本身，而部分来自主干是否开放更新这一训练策略差异。

为更精确地评估 MSL-Adapter 结构本身的贡献，需要在相同训练策略（均采用主干全参更新）下比较 BL 与 BL+MSL。根据第 5 章的详细实验结果，BL$\to$BL+MSL 的增量为 DSC +0.0024（提升 0.25\%）、HD95 $-$0.2292（降低 7.1\%）、ASD $-$0.0298（降低 8.0\%）。该增量幅度较小，在统计检验中未达到严格显著性阈值，因此应将其理解为方向稳定但幅度有限的边界补强，而非大幅度的整体跃升。

相比之下，LoRA 路线的低表现则表明，即便在已有 BL 优化训练信号的前提下，冻结主干所导致的特征适配不充分仍是比结构增强更根本的限制因素。这一对比进一步验证了本文的核心判断：对于医学图像分割这类强依赖空间细节的任务，主干特征的充分适配是性能提升的首要前提，局部结构补强则是在此基础上的有效增量。

\section{最终局部适配器设计}

\subsection{设计动机与关键设计理由}

在排除 Cross-Attention 路线和冻结主干 LoRA 路线之后，本文将增强重点转向局部边界表征本身。已有研究表明，ViT 的全局注意力与卷积的局部归纳偏置具有互补性\cite{dai2021coatnet}。因此，在不显著增加模型复杂度的前提下改善边界质量，一种更自然的思路是在 MedSAM 的特征桥接位置插入轻量级局部适配器，以补充高频纹理与局部结构响应。

具体而言，局部适配器最终被保留，并非因为其结构更复杂，而是因为其设计与当前任务剩余问题更匹配：
\begin{enumerate}
  \item \textbf{双路径卷积}用于同时覆盖较小和中等尺度的局部感受野，使模块能够兼顾边界细节与局部上下文；
  \item \textbf{深度可分离卷积}显著减少参数量，避免为了补充局部信息而引入过重的结构负担；
  \item \textbf{膨胀率 $d=2$}在当前特征分辨率下提供了适中的感受野扩展，同时避免过大的栅格效应；
  \item \textbf{桥接位置插入}能够在不干扰编码器主体建模过程的前提下，将增强后的局部特征直接供给 Mask Decoder 使用；
  \item \textbf{残差连接}降低了对预训练特征分布的破坏风险，使其更适合作为在强基线上进行的局部补强模块。
\end{enumerate}

从设计逻辑上看，上述五点并非彼此独立，而是共同服务于同一目标：在尽量不破坏 MedSAM 原有全局语义能力的前提下，将新增容量集中投入到最易出现剩余误差的位置。双路径与 dilation 负责扩展局部感受野覆盖范围，深度可分离卷积负责控制复杂度，桥接插入与残差连接则负责降低对基座特征分布连续性的干扰。

\subsection{模块结构}

本文最终保留的局部适配器为 Multi-Scale Local Adapter（MSL-Adapter）。已有研究表明，局部卷积与全局注意力机制具有互补性\cite{dai2021coatnet}，在视觉Transformer中引入局部归纳偏置可以提升空间建模能力\cite{li2021localvit}。设 Image Encoder 输出特征图为 $\mathbf{x} \in \mathbb{R}^{B \times 256 \times 64 \times 64}$，其前向计算过程如下。

\textbf{第一步：双路径局部特征提取。}
\begin{equation}
\mathbf{f}_1 = \text{GELU}\left(\text{DWConv}_{3 \times 3}^{d=1}(\mathbf{x})\right), \quad
\mathbf{f}_2 = \text{GELU}\left(\text{DWConv}_{3 \times 3}^{d=2}(\mathbf{x})\right)
\end{equation}

其中，$\mathbf{f}_1$ 对应标准 $3\times3$ 深度可分离卷积分支，$\mathbf{f}_2$ 对应膨胀率为 2 的深度可分离卷积分支，用于覆盖更大的局部感受野。

\textbf{第二步：跨尺度融合。}
\begin{equation}
\mathbf{f}_{cat} = [\mathbf{f}_1 \| \mathbf{f}_2] \in \mathbb{R}^{B \times 512 \times 64 \times 64}
\end{equation}
\begin{equation}
\mathbf{f}_{out} = \text{Conv}_{1 \times 1}(\mathbf{f}_{cat}) \in \mathbb{R}^{B \times 256 \times 64 \times 64}
\end{equation}

\textbf{第三步：残差注入。}
\begin{equation}
\mathbf{y} = \mathbf{x} + \mathbf{f}_{out}
\label{eq:lg_residual}
\end{equation}

局部适配器采用双路径局部特征提取与残差注入的设计。其核心思路在于：通过两个不同感受野的深度可分离卷积分支分别提取局部细节与较大尺度上下文，再利用逐点卷积完成跨尺度融合，最后通过残差方式回注到原始桥接特征中。这样的设计既保留了预训练特征分布的连续性，又为后续 Mask Decoder 提供了更充分的局部结构信息。

图~\ref{fig:lg_adapter} 和图~\ref{fig:adapter_pipeline} 分别展示了模块内部结构及其在 MedSAM 推理管线中的插入位置。该设计并未改动 MedSAM 主干的整体框架，而是以较小代价对局部信息流进行了补充，因此更符合本文“最小有效组合”的设计原则。

本文仅验证了将适配器插入 Image Encoder 与 Mask Decoder 之间的桥接位置这一种方案，其他插入位置的效果可在后续工作中探索。

此外，本文适配器采用二维卷积操作，仅在单张切片的特征图上进行局部增强，未利用 CT 体积数据中相邻切片之间的三维上下文信息。这一设计选择与 MedSAM 本身基于二维切片输入的推理范式保持一致，但也意味着适配器无法捕捉跨切片的连续性信息（如器官在 z 轴方向的形态连贯性）。对于食管、十二指肠等在切片间形态变化较大的器官，引入三维或 2.5D 局部特征增强可能带来改善，这也是后续值得探索的方向之一。

\subsection{组件消融实验}

为验证 MSL-Adapter 中各设计选择的必要性，本文进一步对其核心组件进行消融实验。表~\ref{tab:adapter_ablation}展示了逐一移除或简化关键组件后的性能变化。

从表~\ref{tab:adapter_ablation}可以得到以下结论：

\begin{enumerate}
  \item \textbf{残差连接影响最大。}MSL-nores 去除残差连接后 DSC 下降最为显著（0.9521 vs 0.9562），不仅远低于完整 BL+MSL，甚至低于未加任何适配器的 BL 基线（0.9538）。这意味着缺少残差连接时，适配器的输出不但未能补强边界表征，反而破坏了编码器已有的全局语义特征分布，导致性能不升反降。这一结果从反面证明了残差连接在保持预训练特征分布连续性方面的关键作用。
  \item \textbf{多尺度设计（膨胀率差异）的贡献有限。}MSL-nodil 将两个分支的膨胀率统一为 $d=1$ 后，DSC（0.9564）略高于完整版（0.9562），但 HD95 指标上完整版更优（3.0127 vs 2.9812）。考虑到差异极小（DSC 相对变化 0.02\%），本文仍保留 $d=1$ 和 $d=2$ 的组合设计，以在不同感受野下提供更丰富的局部表征。
  \item \textbf{单分支设计也导致性能下降。}MSL-single 仅保留一个 $d=1$ 分支，虽然参数量减半，但 DSC 下降至 0.9558，表明双路径结构的跨尺度融合确实贡献了额外的表征丰富度。
\end{enumerate}

综合来看，MSL-Adapter 的各设计选择均有实验依据支撑。其中残差连接的贡献最为显著（去除后性能低于未加适配器的 BL 基线），这与本文“在强基线上进行最小有效补强”的设计原则一致——保持与预训练特征的连续性是局部增强模块有效工作的前提。与此同时，双路径与膨胀率差异的影响幅度相对较小（MSL-single 与完整版 DSC 差异为 0.0004，相对变化 0.04\%；MSL-nodil 与完整版结果非常接近），表明当前设计中残差连接是关键组件，而多尺度结构提供的是边际层面的增益。

\section{轻量性与合理性分析}

\subsection{参数量比较}

局部适配器的额外参数量由两层深度可分离卷积和一层逐点卷积构成，总计约 136,448 个参数，仅占 MedSAM 完整模型参数量的约 0.15\%。如表~\ref{tab:route_selection} 所示，该参数量与 BL+LoRA-r4（147,456）处于同一数量级，但二者在性能上存在显著差异（DSC: 0.9562 vs 0.9328，提升 2.5 个百分点），这表明最终效果的决定因素并非参数量的绝对大小，而是参数以何种形式、在何种位置参与表征重塑。

从部署角度看，这一点同样重要。医学图像分割方法若要具备应用价值，不能只追求离线评测中的最好数值，还需要考虑额外复杂度是否可控。局部适配器之所以在本文中更具吸引力，也在于它并未改变 MedSAM 的整体使用方式：输入仍然是图像与提示，主干推理流程并未被重写，附加模块只在中间特征层提供局部补强。

\subsection{推理开销分析}

由于局部适配器仅工作在 $64\times64$ 的桥接特征图上，其附加计算量较低。在实际测试中（单张 V100 GPU，batch\_size=1），MedSAM 基线单样本推理延迟约 42 ms，插入适配器后增至约 43 ms，额外开销不超过 1 ms（相对增加约 2.4\%）。相比之下，BL+CA 路线需要在推理阶段额外编码参考样本，实际部署负担更大。这一轻量化设计与深度可分离卷积\cite{howard2017mobilenets}的高效性密切相关。

\section{本章小结}

本章围绕“微调/适配路线如何被筛选出来”展开论证。在固定 BL 的前提下，Cross-Attention 融合路线未带来稳定收益，LoRA 不同秩设置虽然随秩增大有所改善，但整体仍无法替代开放主干的特征适配能力。相比之下，局部适配路线在保持较低额外参数与较小推理开销的同时，取得了当前最优结果。因此，本文最终锁定“Balance Loss + 主干全参更新 + 局部适配器”为后续统一展示的最终方案。由此，第 4 章完成的是“路线选择”的任务；第 5 章将只展示最终保留方案的整体证据，而不再回放完整筛选过程。
