\chapter{微调路线比较与局部适配方案选择}

在第3章锁定 A3R3 作为统一损失主干之后，本文进一步探讨另一关键问题：在训练信号已得到优化的前提下，如何继续改善 MedSAM 的局部边界表征。本章的核心关注点并非将某个模块预设为既定创新点，而是在固定 A3R3 的条件下，比较不同微调与结构增强策略的适用性，回答最终保留局部适配路线而非 LoRA 或其他方案的原因。因此，本章重点在于通过统一比较完成研究路线的收敛。

\section{研究动机}

第3章结果表明，Balance Loss 能够显著改善训练信号分配，使模型在困难器官和边界相关指标上获得稳定增益。但损失优化并不能完全解决 ViT 编码器在局部高频表征上的先天不足。对于胰腺、食管、十二指肠和肾上腺等边界模糊、形态细长或体积较小的器官而言，仅依赖全局语义建模仍可能出现边界过平滑和局部细节欠刻画的问题。

因此，在固定 A3R3 后，本文继续比较多条可能的增强路线。Cross-Attention 与 LoRA 主要作为负向对照和路线排除依据，局部适配器则是在统一比较后被保留的方案。这样的安排有助于说明最终模型并非简单叠加模块，而是多条路线筛选后留下的最小有效组合。

\section{微调与适配路线统一比较}

\subsection{候选路线与实验设置}

本章在统一的 A3R3 损失主干下，比较以下几类候选路线：
\begin{itemize}
  \item \textbf{A3R3}：仅采用最优损失主干，不进行额外结构增强；
  \item \textbf{C1}：Cross-Attention 融合路线，用于考察跨样本特征融合是否有助于进一步提升表现；
  \item \textbf{LoRA-r4/r8/r16}：冻结 Image Encoder，仅通过不同秩的 LoRA 旁路进行参数高效微调；
  \item \textbf{C3}：在保持全参微调的基础上，引入局部适配器进行结构补强。
\end{itemize}

需要说明的是，C2 编号对应的是早期探索中一种未完成调优的局部适配器变体，因其设计未达到预期效果且与 C3 差异主要在于实现细节，本文不再单独列出，故编号从 C1 直接跳至 C3。

为保证路线比较的公平性，本文在固定 A3R3 损失主干的基础上，对不同结构增强方案采用相同的数据、训练轮数和评估协议，仅改变微调方式或附加结构。通过这种设置，性能差异可以更直接地反映不同结构路线与当前任务需求之间的匹配程度。

对于 LoRA 路线，本文将其作为具有代表性的参数高效微调对照纳入实验。具体而言，LoRA 插入至 Image Encoder 的注意力投影层，冻结原始主干参数，仅更新低秩旁路矩阵以及下游解码相关参数；损失函数、优化器和训练轮数均与 A3R3 保持一致，仅改变 LoRA 秩 $r$。这样的设置有助于回答一个具体问题：在当前腹部多器官分割任务中，是否可以仅依赖参数高效微调，而不开放主干特征继续适配。

因此，第4章的结论并非仅为局部适配器最优的简单判定，而是进一步完成了研究链条的收束：在 A3R3 解决训练信号分配问题之后，后续最值得投入的方向是局部边界建模，而非继续扩大外部参考信息或追求冻结主干条件下的参数效率。这一路线选择使最终方案的组成具有更强的可解释性——C3 并非随意叠加在 A3R3 之上的附加模块，而是围绕剩余误差类型自然延伸的改进措施。

\section{负向路线的筛选意义}

\subsection{Cross-Attention 路线为何未被保留}

C1 的结果表明，跨样本特征融合并未在当前任务中形成正向增益。这一现象并不意味着 Cross-Attention 本身缺乏价值，而是说明其与当前问题并不充分匹配。对于 MedSAM 这类已具有稳定预训练表示的模型而言，在桥接位置直接注入外部参考特征，可能打破原有特征分布的一致性；同时，该路线在推理阶段还需要额外引入参考样本，增加了实现复杂度与部署负担。

因此，C1 的意义不在于“失败”，而在于提供了路线排除的依据：当前任务的主要瓶颈并不在于缺少跨样本先验，而更可能在于局部边界表征尚未被充分补足。

\subsection{LoRA 路线为何不足以成为最终方案}

为进一步判断 LoRA 的退化是否仅仅源于秩过低，可从表~\ref{tab:route_selection} 中 $r=4,8,16$ 的结果进行观察。可以看到，随着秩的增大，LoRA 路线的 DSC 持续上升，HD95 与 ASD 也逐步下降，说明低秩容量不足确实是影响性能的因素之一；但即便提升到 $r=16$，其结果仍明显低于 A3R3。这表明问题并不只是”秩还不够大”，而是冻结主干这一前提本身限制了模型对医学图像域特征的充分重塑。

更重要的是，LoRA 的负向结果并不是孤立的单点现象，而是呈现出“增秩有收益、但整体仍受限”的一致趋势。由此可以判断，当前任务所需的并非单纯的参数效率优化，而是允许主干特征继续适配，并在此基础上针对局部结构缺陷进行补强。这也为后续保留局部适配器提供了直接的比较依据。

若从任务需求进一步理解这一结果，可以发现 LoRA 与当前问题之间存在结构性错位。本文关注的关键难点并非简单的类别判别迁移，而是复杂器官边界、邻接区域与细粒度轮廓的持续重塑，此类误差往往要求主干特征在空间表征上进行更充分的再适配。冻结 Image Encoder 虽保留了预训练表示的稳定性，却也限制了模型对医学图像域细节模式的重新组织能力。因此，LoRA 在本文中的价值并非仅作为一个未达最优的方案，而是进一步表明：当问题核心在于高质量局部重建时，参数高效并不等同于任务高效。

\section{最终局部适配器设计}

\subsection{设计动机}

在排除 Cross-Attention 路线和冻结主干 LoRA 路线之后，本文将增强重点转向局部边界表征本身。已有研究表明，ViT 的全局注意力与卷积的局部归纳偏置具有互补性\cite{dai2021coatnet}。因此，若希望在不显著增加模型复杂度的前提下进一步改善边界质量，一种更自然的思路是在 MedSAM 的特征桥接位置插入轻量级局部适配器，以补充高频纹理与局部结构响应。

\subsection{模块结构}

本文最终保留的局部适配器为 Multi-Scale Local Adapter（MSL-Adapter）。设 Image Encoder 输出特征图为 $\mathbf{x} \in \mathbb{R}^{B \times 256 \times 64 \times 64}$，其前向计算过程如下。

\textbf{第一步：双路径局部特征提取。}
\begin{equation}
\mathbf{f}_1 = \text{GELU}\left(\text{DWConv}_{3 \times 3}^{d=1}(\mathbf{x})\right), \quad
\mathbf{f}_2 = \text{GELU}\left(\text{DWConv}_{3 \times 3}^{d=2}(\mathbf{x})\right)
\end{equation}

其中，$\mathbf{f}_1$ 对应标准 $3\times3$ 深度可分离卷积分支，$\mathbf{f}_2$ 对应膨胀率为 2 的深度可分离卷积分支，用于覆盖更大的局部感受野。

\textbf{第二步：跨尺度融合。}
\begin{equation}
\mathbf{f}_{cat} = [\mathbf{f}_1 \| \mathbf{f}_2] \in \mathbb{R}^{B \times 512 \times 64 \times 64}
\end{equation}
\begin{equation}
\mathbf{f}_{out} = \text{Conv}_{1 \times 1}(\mathbf{f}_{cat}) \in \mathbb{R}^{B \times 256 \times 64 \times 64}
\end{equation}

\textbf{第三步：残差注入。}
\begin{equation}
\mathbf{y} = \mathbf{x} + \mathbf{f}_{out}
\label{eq:lg_residual}
\end{equation}

局部适配器采用双路径局部特征提取与残差注入的设计。其核心思路在于：通过两个不同感受野的深度可分离卷积分支分别提取局部细节与较大尺度上下文，再利用逐点卷积完成跨尺度融合，最后通过残差方式回注到原始桥接特征中。这样的设计既保留了预训练特征分布的连续性，又为后续 Mask Decoder 提供了更充分的局部结构信息。

图~\ref{fig:lg_adapter} 和图~\ref{fig:adapter_pipeline} 分别展示了模块内部结构及其在 MedSAM 推理管线中的插入位置。可以看到，该设计并未改动 MedSAM 主干的整体框架，而是以较小代价对局部信息流进行了补充，因此更符合本文“最小有效组合”的设计原则。

\subsection{关键设计理由}

局部适配器最终被保留，并非因为其结构更复杂，而是因为其设计与当前任务剩余问题更加匹配。具体而言：
\begin{enumerate}
  \item \textbf{双路径卷积}用于同时覆盖较小和中等尺度的局部感受野，使模块能够兼顾边界细节与局部上下文；
  \item \textbf{深度可分离卷积}显著减少参数量，避免为了补充局部信息而引入过重的结构负担；
  \item \textbf{膨胀率 $d=2$}在当前特征分辨率下提供了适中的感受野扩展，同时避免过大的栅格效应；
  \item \textbf{桥接位置插入}能够在不干扰编码器主体建模过程的前提下，将增强后的局部特征直接供给 Mask Decoder 使用；
  \item \textbf{残差连接}降低了对预训练特征分布的破坏风险，使其更适合作为在强基线上进行的局部补强模块。
\end{enumerate}

从设计逻辑上看，上述五点并非彼此独立，而是共同服务于同一目标：在尽量不破坏 MedSAM 原有全局语义能力的前提下，将新增容量集中投入到最易出现剩余误差的位置。双路径与 dilation 负责扩展局部感受野覆盖范围，深度可分离卷积负责控制复杂度，桥接插入与残差连接则负责降低对基座特征分布连续性的干扰。局部适配器之所以适合作为最终保留方案，并非因为其比 LoRA 参数更多或比 Cross-Attention 更新颖，而是因为其在设计目标、注入位置与复杂度控制三者之间取得了更适合当前任务的平衡。

  \item \textbf{多尺度设计（膨胀率差异）的贡献次之。}C3-nodil 将两个分支的膨胀率统一为 $d=1$，DSC 略有下降（0.9608 vs 0.9620），说明不同感受野的覆盖确实有助于边界建模。膨胀率为 2 的分支提供了更大的局部上下文，使模块能够同时捕捉精细边界和邻近结构信息。
  \item \textbf{单分支设计也导致性能下降。}C3-single 仅保留一个 $d=1$ 分支，虽然参数量减半，但 DSC 下降至 0.9605，说明双路径结构的跨尺度融合确实贡献了额外的表征丰富度。
\end{enumerate}

综合来看，MSL-Adapter 的每个设计选择都有实验依据支撑，并非冗余堆叠。三个消融变体均导致不同程度的性能下降，其中残差连接的贡献最为显著，这与本文"在强基线上进行最小有效补强"的设计原则一致——保持与预训练特征的连续性是局部增强模块有效工作的前提。

\section{轻量性与合理性分析}

\subsection{参数量比较}

局部适配器的额外参数量由两层深度可分离卷积和一层逐点卷积构成，总计约 136,448 个参数，仅占 MedSAM 完整模型参数量的约 0.15\%。如表~\ref{tab:route_selection} 所示，该参数量与 LoRA-r4（147,456）处于同一数量级，但二者在性能上存在显著差异，这进一步说明最终效果的决定因素并非参数量的绝对大小，而是参数以何种形式、在何种位置参与表征重塑。

从部署角度看，这一点同样重要。医学图像分割方法若要具备进一步应用价值，不能只追求离线评测中的最好数值，还需要考虑额外复杂度是否可控。局部适配器之所以在本文中更具吸引力，也在于它并未改变 MedSAM 的整体使用方式：输入仍然是图像与提示，主干推理流程并未被重写，附加模块只在中间特征层提供局部补强。因此，相较于需要外部参考样本的 Cross-Attention 路线或效果明显受限的冻结主干 LoRA 路线，局部适配器在“收益—复杂度”这一综合标准下表现得更均衡。

\subsection{推理开销分析}

由于局部适配器仅工作在 $64\times64$ 的桥接特征图上，其附加计算量较低。实际测试中，插入适配器后单样本推理延迟增加不超过 1 ms。相比之下，C1 路线需要在推理阶段额外编码参考样本，实际部署负担更大。因此，从性能收益与额外代价的综合角度看，局部适配路线也是更合理的选择。

这也进一步解释了本文最终保留”局部适配器 + 全参微调”而非更复杂外部增强链路的原因。对于医学分割方法而言，若某方案仅能在离线实验中取得有限增益，却显著改变使用流程或引入额外输入依赖，其综合价值往往受到削弱。局部适配器之所以更适合作为最终方案，在于它将额外代价限制在中间特征层内部：训练时无需重构整套框架，推理时亦无需额外参考样本、额外提示形式或额外后处理阶段。由此，本文最终方案不仅在数值上更优，在实现路径上也更接近可复用的最小有效增强。

\section{本章小结}

本章围绕“微调/适配路线如何被筛选出来”展开论证。在固定 A3R3 的前提下，Cross-Attention 融合路线未带来稳定收益，LoRA 不同秩设置虽然随秩增大有所改善，但整体仍无法替代开放主干的特征适配能力。相比之下，局部适配路线在保持较低额外参数与较小推理开销的同时，取得了当前最优结果。因此，本文最终锁定“Balance Loss + 全参微调 + 局部适配器”为后续统一展示的最终方案。由此，第4章完成的是“路线选择”的任务；第5章将只展示最终保留方案的整体证据，而不再回放完整筛选过程。
