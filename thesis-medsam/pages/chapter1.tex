\chapter{绪论}

\section{研究背景与意义}

医学图像分割是计算机辅助诊断的基础任务，直接影响器官体积估计、病灶边界识别及治疗方案制定\cite{litjens2017survey}。深度学习推动了从 FCN\cite{long2015fcn}、U-Net\cite{ronneberger2015unet}到 Transformer 架构\cite{chen2021transunet,cao2022swinunet}的演进。近年来，Segment Anything Model（SAM）\cite{kirillov2023segment}等视觉基础模型的出现为医学分割提供了新的技术路径。MedSAM\cite{ma2024medsam}作为 SAM 的医学迁移版本，在提示式分割上展现出较强能力，但在腹部多器官 CT 等复杂场景中仍存在训练信号分配不均和局部边界表征不足的问题。

腹部多器官 CT 分割是验证方法有效性的理想场景：器官间体积、形态、对比度差异显著，小器官（胰腺、肾上腺）和细长结构（食管、十二指肠）对训练信号分配和局部边界建模提出更高要求\cite{hesamian2019survey}。选择该场景既能检验整体分割能力，又能敏感暴露 MedSAM 在训练信号设计与局部结构建模方面的不足。

从研究层面而言，视觉基础模型的迁移正在改变医学图像分割的技术路径\cite{bommasani2021foundation,moor2023foundation}。MedSAM 等模型已具备较强的通用表示与提示驱动能力，但如何在不破坏预训练表示优势的前提下进一步重构训练信号、补足局部边界表征、提升困难器官的可分性，仍是值得深入探讨的问题。本文围绕 MedSAM 在腹部多器官 CT 分割中的能力边界进行系统性优化，通过统一实验协议下的逐步筛选，构建起一条由问题定义、路线比较与负向结果排除直至最终方案保留的完整证据链。

\section{国内外研究现状}

\subsection{医学图像分割模型发展}

医学图像分割方法经历了从传统方法到深度学习，再到视觉基础模型迁移的演进\cite{wang2022medseg_survey}。U-Net\cite{ronneberger2015unet}通过编码器—解码器结构和跳跃连接机制，奠定了医学分割的经典范式。此后，UNet++\cite{zhou2018unetpp}、Attention U-Net\cite{oktay2018attention}等工作围绕多尺度融合和注意力建模持续改进。nnU-Net\cite{isensee2021nnunet}通过自动化配置成为医学分割的强基线。

随着 Transformer 架构进入视觉领域，TransUNet\cite{chen2021transunet}、Swin-Unet\cite{cao2022swinunet}、UNETR\cite{hatamizadeh2022unetr}等方法验证了长距离依赖建模的重要性。SAM\cite{kirillov2023segment}推动了提示式分割的发展，MedSAM\cite{ma2024medsam}将其迁移到医学场景。围绕医学任务适配，SAMed\cite{zhang2024samed}、Medical SAM Adapter\cite{wu2023medsamadapter}等工作探索了基础模型的高效适配方式\cite{mazurowski2023sam_survey}。

已有研究表明：基础模型迁移为医学分割提供了新起点，但任务特异性的损失设计与局部结构补强仍然必要。本文选择以 MedSAM 为基座，重点在于当前研究价值更集中于在已有强初始化基础上补足任务特异性短板。

\subsection{不平衡学习方法}

类别不平衡是医学图像分割中的长期核心问题\cite{litjens2017survey}。在腹部多器官分割中，背景像素通常占据绝大多数，而小器官和边界区域的有效监督信号相对稀缺。

针对类别间不平衡，Class-Balanced Loss\cite{cui2019classbalanced}通过有效样本数建模多数类信息冗余，给出了系统化的类别重加权方法。针对困难样本学习，OHEM\cite{shrivastava2016ohem}提出在线困难样本挖掘策略，Focal Loss\cite{lin2017focal}通过连续调制因子降低易样本权重。

在损失函数设计方面，Dice Loss\cite{milletari2016vnet}因其对不平衡数据的天然鲁棒性而被广泛使用。Boundary Loss\cite{kervadec2019boundary}从距离度量角度直接优化边界质量，Active Boundary Loss\cite{wang2022activeboundaryloss}通过动态聚焦边界区域提高边界预测精度。

现有方法大多从“重叠度优化”或“连续调制”角度缓解不平衡，但对类别间重平衡与类别内困难像素加权的联合、可解释建模仍有改进空间。本文第 3 章正是在这一问题上，对 MedSAM 的训练信号进行任务驱动的重构。

\subsection{参数高效微调与局部适配研究}

随着视觉基础模型参数规模持续增长，全参数微调的成本问题日益突出。参数高效微调（PEFT）技术通过冻结大部分预训练参数、仅更新少量任务相关参数来实现任务适配\cite{ding2022peftsurvey}。LoRA\cite{hu2022lora}通过低秩矩阵分解建模权重增量，在自然语言处理任务上取得了显著效果。在视觉领域，AdaptFormer\cite{chen2022adaptformer}和Visual Prompt Tuning\cite{jia2022vpt}分别从适配器和提示学习角度探索了高效微调方法。

然而，在医学图像分割这类强依赖空间重建与边界细节的任务中，单纯冻结主干并不总能维持性能。已有研究指出，ViT 的全局注意力与 CNN 的局部归纳偏置具有较强互补性\cite{dai2021coatnet}。在医学 SAM 适配方向，MA-SAM\cite{chen2024masam} 和 Medical SAM Adapter\cite{wu2023medsamadapter}通过插入卷积适配模块提升空间建模能力。这些工作说明：在医学场景中，合理的结构补强可能比单纯追求参数效率更重要。本文第 4 章将围绕这一问题，对多条微调与适配路线进行系统比较，并最终收敛到局部适配方案。

\subsection{视觉基础模型迁移带来的新变化}

视觉基础模型进入医学图像分析后，研究范式出现了明显变化。传统医学分割研究往往从网络结构本身出发，围绕编码器、解码器、跳跃连接或注意力模块进行任务专用设计；而以 SAM、MedSAM 为代表的基础模型路径，则更强调“先获得强通用表征，再进行任务适配”。这意味着研究重点不再只是设计一个从头训练的新网络，而是需要进一步探讨：对于已经具备较强初始化能力的基础模型，下游性能的主要瓶颈来源何在。

这一变化带来了两个直接影响。其一，传统方法中许多从零建模的问题在基础模型场景下被部分弱化。例如，MedSAM 已能在多种医学分割任务中提供有效的分割初始化，因此简单重复构造新的主干网络未必能带来显著收益。其二，新的问题开始凸显，即如何在保留基础模型已有优势的同时，对医学任务的局部困难区域进行低破坏性补强。本文第 3 章与第 4 章的两条主线本质上均建立在这一认识之上：第 3 章回答基础模型在当前任务中尚缺何种训练信号，第 4 章回答在训练信号重构后尚缺何种局部表征。

本文不试图将结论直接外推为通用医学分割方法，而是以腹部多器官 CT 为统一验证场景，聚焦 MedSAM 在该类任务中的两个关键问题：训练信号分配不足与局部边界表征不足。围绕这两个问题，研究目标定位为：以 MedSAM 为基座，构建一条”问题发现—针对性修正—逐步筛选—最终验证”的优化链。具体而言，先通过损失策略重构训练信号，再通过微调/适配路线比较补足局部边界表征，最终形成用于统一展示的最小有效组合。LoRA、Cross-Attention 等未被保留的方案作为研究路线收敛的排除性证据，而非失败记录。

如图~\ref{fig:tech_roadmap}所示，本文采用“损失筛选 → 路线筛选 → 结果验证”的研究路径。全部实验在 GT box prompt 条件下进行，以 15 个测试病例为统计单位，确保方案间的可比性。具体包括三个步骤：损失策略筛选、适配路线筛选和最终结果验证。

该技术路线具有明确的问题导向：第一阶段确认训练信号是否为当前性能瓶颈的主要来源，第二阶段判断在训练信号重构后剩余误差是否主要表现为局部边界表征不足。此外，保留 BL-$\alpha$1.0 退化、Cross-Attention 回落、冻结主干 LoRA 效果受限等负向结果作为路线收敛的排除性证据，以增强最终方案的说服力。

\section{主要工作与贡献}

围绕上述目标，本文的主要工作与贡献可概括为以下三点：

\begin{enumerate}
  \item 形式化定义了提示式二值分割场景下的双层不平衡问题，设计了 Balance Loss 框架。该框架通过 Inter-CBL 和 Intra-CBL 分别处理类别间与类别内失衡，并结合两阶段训练策略确保稳定优化。实验表明该方法优于 Focal Loss 等统一调制策略，相较基线在当前评估协议下带来了稳定增益，说明训练信号重构是整体性能提升的首要来源。

  \item 完成了面向 MedSAM 的多条微调/适配路线的系统比较，并保留局部适配方案。将 LoRA、Cross-Attention 融合与局部适配器等路线统一纳入比较框架。实验表明，在当前任务和配置下，局部适配方案更能补足边界相关表征，从而形成联合平衡损失与局部适配的最终方案。LoRA 和 Cross-Attention 的负向结果作为路线收敛的排除性证据予以保留。

  \item 通过系统消融与路线对比，建立了当前任务中不同优化策略的适用性判据。实验表明，训练信号重构是整体性能提升的首要来源，而局部边界补强在此基础上提供有效补充；Focal Loss 失效、Cross-Attention 回落与冻结主干 LoRA 退化等负向结果不仅作为路线收敛的排除性证据，也为类似任务中的策略选择提供了参考，使最终方案的选择具有更强的可解释性。
\end{enumerate}

\section{论文组织结构}

全文共分六章：

\begin{itemize}
  \item 第1章为绪论，介绍研究背景、相关工作、论文定位与整体技术路线。
  \item 第2章介绍相关理论基础，包括 MedSAM 架构原理、不平衡学习理论、PEFT 技术及局部适配相关理论。
  \item 第3章聚焦 Balance Loss 的配置选择，回答“损失策略如何被筛选出来”。
  \item 第4章聚焦微调与结构增强路线比较，回答“为什么最终选择局部适配而不是其他路线”。
  \item 第5章展示最终保留方案的整体结果、逐器官表现、边界分析、定性可视化与局限性讨论。
  \item 第6章总结全文工作，并讨论后续可进一步扩展的研究方向。
\end{itemize}

\section{本章小结}

本章围绕本文的研究问题、研究动机与论证组织给出了整体说明。本文以 MedSAM 为基座，以腹部多器官 CT 为统一验证场景，围绕训练信号重构与局部边界补强两条主线展开优化，并将实验章节组织为先筛选后展示的研究型叙事结构，为后续章节的展开奠定基础。
