\chapter{绪论}

\section{研究背景与意义}

医学图像分割是计算机辅助诊断、术前规划和放疗勾画中的关键基础能力\cite{litjens2017survey}。高质量分割结果直接影响器官体积估计、病灶边界判读以及下游治疗决策。相比自然图像任务，医学图像分割具有两个长期痛点：第一，器官或病灶前景像素占比低，训练过程容易被大量背景样本主导；第二，边界区域和低对比区域的困难像素对最终临床可用性影响大，但在常规训练中常被简单样本淹没\cite{hesamian2019survey}。

深度学习技术的发展推动了医学分割方法的持续进步。从全卷积网络（FCN）\cite{long2015fcn}到 U-Net\cite{ronneberger2015unet}，再到 nnU-Net\cite{isensee2021nnunet}和基于 Transformer 的 TransUNet\cite{chen2021transunet}、Swin-Unet\cite{cao2022swinunet}，模型的表征能力不断增强。近年来，Segment Anything Model（SAM）\cite{kirillov2023segment}为统一提示式分割提供了新范式，其后续版本 SAM 2\cite{ravi2024sam2}进一步扩展到视频领域。在医学领域，MedSAM\cite{ma2024medsam}将 SAM 迁移并微调到大规模医学数据，显著提升了跨任务可用性。但在现实复杂的腹部多器官分割任务中，基座模型仍存在"类别不平衡显式建模不足"和"高频边缘特征提取极为欠缺"两个限制。围绕这两个核心限制展开架构与损失层面的改进，具有极大的研究价值与工程价值。

\section{国内外研究现状}

\subsection{医学图像分割模型发展}

医学分割方法经历了从卷积网络到 Transformer，再到视觉基础模型迁移的演进\cite{wang2022medseg_survey}。U-Net\cite{ronneberger2015unet}奠定了编码器-解码器结构的经典范式；nnU-Net\cite{isensee2021nnunet}通过自动化配置在多个医学分割基准上取得了领先性能；TransUNet\cite{chen2021transunet}首次将 Transformer 引入医学分割，验证了全局注意力对长距离依赖建模的有效性。基于提示的通用分割范式将"一个模型适配多任务"从研究概念推向可用框架\cite{kirillov2023segment}。MedSAM\cite{ma2024medsam}的提出则验证了该范式在医学场景中的迁移潜力，而 SAMed\cite{zhang2024samed}、Medical SAM Adapter\cite{wu2023medsamadapter}等后续工作进一步探索了如何将 SAM 高效适配到特定医学任务。

\subsection{不平衡学习方法}

针对长尾问题，Class-Balanced Loss\cite{cui2019classbalanced}通过有效样本数建模多数类信息冗余，给出了系统化重加权方法。针对难样本学习，OHEM\cite{shrivastava2016ohem}提出在线困难样本挖掘，Focal Loss\cite{lin2017focal}通过连续调制因子降低易样本权重。Dice Loss\cite{milletari2016vnet}从集合重叠度角度提供了对不平衡数据的天然鲁棒性。这些思想为医学分割中的"前景稀疏 + 难样本稀缺"问题提供了方法学基础。

\subsection{参数高效微调与空间适配器}

随着大模型的普及，LoRA\cite{hu2022lora}等参数高效微调（PEFT）技术通过冻结主干来极大缩小训练成本。Adapter\cite{houlsby2019adapter}方法则通过在预训练模型层间插入轻量瓶颈模块实现任务适配。然而，在医学图像分割这种强依赖密集空间重塑的任务上，单纯冻结主干往往导致性能塌陷。近期研究表明，ViT 的全局注意力与 CNN 的局部归纳偏置具有高度互补性\cite{dai2021coatnet}，将两者结合可在多种任务上获得更优性能。在医学 SAM 适配领域，I-MedSAM\cite{yue2024imedsam}等工作提出通过频率域或空间域适配器增强高频边缘响应，这为突破基于 ViT 架构的 SAM 模型的性能瓶颈提供了全新思路。

\section{研究问题与挑战}

本文聚焦以下三个核心挑战：

\begin{enumerate}
  \item \textbf{双重不平衡挑战}：类间不平衡导致前景召回受限，类内不平衡导致边界学习不足。现有损失函数（如 Dice+CE 组合）未对此进行显式建模。
  \item \textbf{医疗域强异质性挑战}：冻结大模型主干进行极简微调难以跨越医疗图像复杂的形态学鸿沟。FLARE22\cite{ma2022flare}数据集包含 13 类形态差异巨大的腹部器官，从体积最大的肝脏到微小的肾上腺，要求模型具备强大的特征空间重塑能力。
  \item \textbf{高频特征丢失挑战}：ViT\cite{dosovitskiy2021vit}的全局注意力机制极容易平滑掉器官或病灶的细微物理边缘，而这些边缘信息恰恰是临床应用中最关键的判别依据。
\end{enumerate}

本研究提出了一种"三核驱动"的医学分割架构演进路线：
\begin{enumerate}
  \item \textbf{第一核（损失层）}：构建可解释的联合平衡损失框架（A3R3），将 Inter-CBL 与 Intra-CBL 联合建模，强制模型关注医学困难样本。
  \item \textbf{第二核（架构消融层）}：通过实施极简参数微调（LoRA）\cite{hu2022lora}，反向揭示"全参微调主干对于空间形变学习的极端重要性"。
  \item \textbf{第三核（特征流层）}：在网络深层插入多尺度纯卷积适配器（Local-Global Adapter，简称 LG-Adapter），利用深度可分离卷积\cite{howard2017mobilenets}与膨胀卷积\cite{yu2016dilated}的局部归纳偏置重建器官的高频边缘。
\end{enumerate}

\section{主要贡献}

围绕上述挑战，本文的主要贡献如下：

\begin{enumerate}
  \item \textbf{理论维度}：提出 Balance Loss 框架，将 Inter-CBL 与 Intra-CBL 结合并引入两阶段训练策略，通过严格的假设检验（单变量剥离 R2/R3）定位退化根因，显著提升了 Baseline 性能（DSC 从 0.941 跃升至 0.959）。
  \item \textbf{架构维度}：设计并验证了多尺度 Local-Global 适配器，通过双路径深度可分离卷积完美弥补了 SAM 在边缘划分上的弱视，刷新了医学多器官分割的上限（DSC 达 0.9620，HD95 降至 2.91）。
  \item \textbf{工程维度}：通过详实的 LoRA 消融实验（DSC 退化至 0.879），为医学大模型领域"是否必须解冻主干"提供了极具价值的负向参考结论和完整的复现证据链。
\end{enumerate}

\section{论文组织结构}

全文共分六章：

\begin{itemize}
  \item 第1章为绪论，介绍研究背景、现状、挑战与本文的三大核心创新点。
  \item 第2章介绍相关理论基础，包括 MedSAM 架构原理、不平衡学习理论、PEFT 技术及卷积-ViT 互补性理论。
  \item 第3章给出基于 Balance Loss 的困难样本挖掘与梯度重整策略，包含完整的消融实验与假设检验过程。
  \item 第4章详细分析 LoRA 冻结主干的局限性消融，并给出 Local-Global 适配器的完整设计与理论分析。
  \item 第5章汇总同口径测试集下的综合实验结果、完整消融路径、定性分析与深入讨论。
  \item 第6章总结全文并探讨未来可能的研究延伸方向。
\end{itemize}

\section{本章小结}

本章围绕"为什么做、做什么、如何做"给出了完整问题陈述。本文以 MedSAM 为基座，采用损失重构结合多尺度架构适配器的"三核驱动"路线，构建了一套性能卓越且理论完备的腹部多器官高精度分割系统。
