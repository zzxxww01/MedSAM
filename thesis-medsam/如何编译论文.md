# 如何编译论文

在 PowerShell 中进入论文目录：

```powershell
cd C:\Users\DELL\Desktop\MedSAM\thesis-medsam
```

生成正式版和盲审版的临时入口文件：

```powershell
@'
\input{thesis_common.tex}
'@ | Set-Content -LiteralPath .\build_formal.tex -Encoding UTF8

@'
\def\BlindReviewMode{1}
\input{thesis_common.tex}
'@ | Set-Content -LiteralPath .\build_blind.tex -Encoding UTF8
```

编译正式版：

```powershell
xelatex -interaction=nonstopmode -halt-on-error -jobname=formal_build build_formal.tex
bibtex formal_build
xelatex -interaction=nonstopmode -halt-on-error -jobname=formal_build build_formal.tex
xelatex -interaction=nonstopmode -halt-on-error -jobname=formal_build build_formal.tex
```

编译盲审版：

```powershell
xelatex -interaction=nonstopmode -halt-on-error -jobname=blind_build build_blind.tex
bibtex blind_build
xelatex -interaction=nonstopmode -halt-on-error -jobname=blind_build build_blind.tex
xelatex -interaction=nonstopmode -halt-on-error -jobname=blind_build build_blind.tex
```

把生成结果复制为最终文件名：

```powershell
@'
from pathlib import Path
from shutil import copy2
root = Path(r'C:\Users\DELL\Desktop\MedSAM\thesis-medsam')
copy2(root / 'formal_build.pdf', root / '基于平衡损失与局部适配的医学图像分割_正式版.pdf')
copy2(root / 'blind_build.pdf', root / '基于平衡损失与局部适配的医学图像分割.pdf')
print('done')
'@ | python -
```

最终文件：

- `基于平衡损失与局部适配的医学图像分割_正式版.pdf`
- `基于平衡损失与局部适配的医学图像分割.pdf`
