## 📌 使用建议

### 答辩前1周
1. 通读 `01-答辩流程与要求.md`，确认所有材料准备齐全
2. 精读 `03-论文核心内容速查.md`，熟悉论文所有细节
3. 开始准备答辩PPT

### 答辩前3天
1. 根据 `02-答辩讲稿与应答策略.md` 准备讲稿
2. 对着镜子或录音练习，控制时间
3. 熟记7个高频追问的标准回答

### 答辩前1天
1. 再次检查答辩材料是否齐全
2. 打印修改报告
3. 准备好答辩PPT和备用U盘
4. 早点休息，保持良好状态

### 答辩当天
1. 提前30分钟到达答辩地点
2. 测试PPT播放
3. 深呼吸，保持自信
4. 记住：诚实为上，不懂的不要装懂
